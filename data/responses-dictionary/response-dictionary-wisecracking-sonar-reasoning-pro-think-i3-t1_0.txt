## **Implementation**

```python
import re

def build_dictionary_index(dictionary: dict) -> dict:
    """Create a case-insensitive normalized index for fast lookups"""
    index = {}
    for original_key, value in dictionary.items():
        # Normalize to lowercase and ignore word separators
        normalized_key = re.sub(r'\W+', '', original_key).lower()
        if normalized_key not in index:
            index[normalized_key] = set()
        index[normalized_key].add(value)
    return index

def annotate(tokens: list[str], dictionary_index: dict) -> list[tuple[str, set]]:
    """Annotate tokens with dictionary entries, including nested compounds"""
    n = len(tokens)
    annotations = [set() for _ in range(n)]
    
    # Step 1: Individual word matches
    for i, token in enumerate(tokens):
        key = re.sub(r'\W+', '', token).lower()
        if key in dictionary_index:
            annotations[i].update(dictionary_index[key])
    
    # Step 2: Compound phrase matches (all possible sequences)
    max_length = len(tokens)
    for i in range(n):
        # Check sequences ending at i
        for j in range(i, max(-1, i - max_length) - 1, -1):
            compound = tokens[j:i+1]
            # Create normalized key without separators
            key = re.sub(r'\W+', '', ''.join(compound)).lower()
            if key in dictionary_index:
                # Add annotation to all tokens in the compound
                for k in range(j, i+1):
                    annotations[k].update(dictionary_index[key])
    
    return [(token, ann) for token, ann in zip(tokens, annotations)]
```

## **How It Works**

1. **Dictionary Indexing**  
   `build_dictionary_index` preprocesses entries by:
   - Removing non-word characters (separators)
   - Converting to lowercase
   - Mapping to the original entry IDs

2. **Annotation Process**  
   For every token:
   - **Individual Matches**: Directly check the normalized token against the index.
   - **Compound Matches**: Check all possible sequences ending at the token:
     - Build a normalized key by concatenating tokens and removing separators
     - For matching sequences, annotate **all tokens** in the sequence

3. **Efficiency**  
   - **Case Insensitivity**: Lightweight regex cleanup replaces manual string manipulations
   - **Dynamic Annotation Combination**: Earlier detection (smaller sequences) inform larger compound checks
   - **Non-Destructive Updates**: Separate annotation storage before final collection
