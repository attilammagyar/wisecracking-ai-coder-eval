## Solution Overview

### Data Structure
I'll use a **trie (prefix tree)** to store normalized dictionary entries. This allows efficient prefix matching and helps identify all possible phrases starting at any position. Each trie node will store:
- Children nodes for the next word in a phrase
- Set of dictionary entry IDs if this node represents a complete dictionary entry
- A special marker for compound words (entries without spaces)

### Normalization
- Convert all dictionary keys and tokens to lowercase for case-insensitive matching
- Split compound phrases into word sequences, preserving information about whether they're phrases or compound words

### Lookup Algorithm
1. Iterate through each token position
2. At each position, try to match sequences starting from that position
3. For word tokens: check both individual matches and start phrase matching
4. For separator tokens: continue ongoing phrase matches
5. Handle compound words by concatenating consecutive word tokens

### Annotation Assignment
- Track all matches found at each position
- Distribute annotations across all tokens that participate in each match
- Separators get annotations only from phrases they're inside of (not leading/trailing)

class TrieNode:
    def __init__(self):
        self.children = {}
        self.entry_ids = set()
        self.is_compound_word = False

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    Parameters:
        dictionary: Mapping strings (keys) to meanings (values).
    """
    root = TrieNode()
    
    for key, value in dictionary.items():
        normalized_key = key.lower()
        
        # Check if this is a compound word (no spaces or separators)
        is_compound = all(c.isalnum() or c in "-'" for c in normalized_key)
        
        if is_compound:
            # Store compound words directly
            node = root
            if normalized_key not in node.children:
                node.children[normalized_key] = TrieNode()
            node = node.children[normalized_key]
            node.entry_ids.add(value)
            node.is_compound_word = True
        
        # Split into words for phrase matching
        words = []
        current_word = []
        for char in normalized_key:
            if char.isalnum() or char in "-'":
                current_word.append(char)
            elif current_word:
                words.append(''.join(current_word))
                current_word = []
        if current_word:
            words.append(''.join(current_word))
        
        # Add to trie
        if words:
            node = root
            for word in words:
                if word not in node.children:
                    node.children[word] = TrieNode()
                node = node.children[word]
            node.entry_ids.add(value)
    
    return root
