## Algorithm Design

### Data Structure for Dictionary Index

I'll use a **trie (prefix tree)** to store normalized dictionary entries. This enables efficient matching of multi-token phrases while scanning through the input tokens. The trie will:
- Store normalized tokens (lowercase, word tokens only)
- Mark end nodes with the original dictionary entry IDs
- Allow us to track multiple simultaneous partial matches as we scan

### Normalization Strategy

1. **Case normalization**: Convert to lowercase for matching
2. **Separator handling**: Extract only word tokens from compound phrases, ignoring separators
3. **Token classification**: Distinguish between word tokens (alphanumeric) and separators

### Lookup Algorithm

The core algorithm uses a "sliding window" approach with simultaneous tracking of multiple potential matches:

1. For each starting position in the token sequence:
   - If it's a word token, start a new trie traversal
   - Track all active traversals simultaneously
   - When a traversal reaches a terminal node, record the match
   - Continue traversals to find longer phrases

2. For each match found:
   - Annotate all participating tokens
   - Skip leading separators
   - Include inner separators
   - Skip trailing separators

```python
import collections.abc

class TrieNode:
    def __init__(self):
        self.children = {}
        self.entries = []  # Dictionary entry IDs that end at this node

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    Parameters:
        dictionary: Mapping strings (keys) to meanings (values).
    """
    root = TrieNode()
    
    for phrase, entry_id in dictionary.items():
        # Normalize and extract word tokens only
        tokens = []
        for token in phrase.split():
            # Keep only alphanumeric characters from each token
            word_chars = ''.join(c for c in token if c.isalnum())
            if word_chars:
                tokens.append(word_chars.lower())
        
        # Add to trie
        if tokens:
            node = root
            for token in tokens:
                if token not in node.children:
                    node.children[token] = TrieNode()
                node = node.children[token]
            node.entries.append(entry_id)
    
    return root

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.

    Parameters:
        dictionary_index:   A dictionary index created by build_dictionary_index()
        tokens:             The tokens to be annotated.

    Return:
        annotated_tokens:   A list containing (token, annotations) pairs for each token in tokens.
    """
    tokens = list(tokens)
    n = len(tokens)
    annotations = [set() for _ in range(n)]
    
    def is_word_token(token):
        return any(c.isalnum() for c in token)
    
    def normalize_token(token):
        # Extract alphanumeric characters and convert to lowercase
        word_chars = ''.join(c for c in token if c.isalnum())
        return word_chars.lower() if word_chars else None
    
    # Try starting a match from each position
    for start_pos in range(n):
        if not is_word_token(tokens[start_pos]):
            continue
            
        # Track current position in trie
        node = dictionary_index
        word_positions = []  # Positions of word tokens in current match
        
        # Try to extend the match as far as possible
        pos = start_pos
        while pos < n:
            if is_word_token(tokens[pos]):
                normalized = normalize_token(tokens[pos])
                if normalized and normalized in node.children:
                    node = node.children[normalized]
                    word_positions.append(pos)
                    
                    # Check if we have a complete match
                    if node.entries:
                        # Find the range to annotate (excluding leading/trailing separators)
                        first_word_pos = word_positions[0]
                        last_word_pos = word_positions[-1]
                        
                        # Annotate all tokens in the range
                        for i in range(first_word_pos, last_word_pos + 1):
                            annotations[i].update(node.entries)
                else:
                    break  # No match, stop extending
            
            pos += 1
    
    annotated_tokens = [(tokens[i], annotations[i]) for i in range(n)]
    return annotated_tokens
```
