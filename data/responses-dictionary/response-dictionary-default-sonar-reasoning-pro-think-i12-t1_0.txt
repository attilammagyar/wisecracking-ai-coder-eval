    n = len(annotated_tokens)

### Approach
The solution uses a two-tiered approach to efficiently handle both individual words and compound phrases:

1. **Preprocessing for Speed**  
   During dictionary initialization (`build_dictionary_index`), entries are normalized in two ways:
   - **Original Text Matching**: Words are stored by their exact lowercase form (including spaces contrasted to handle concatenated tokens).
   - **Normalized Phrase Matching**: Entries are converted to lowercase with all non-alphanumeric separators replaced by spaces.

2. **Annotation via Sliding Window**  
   The annotation process uses a sliding window approach to check all possible subranges of tokens:
   - **Non-Separator Filtering**: Identifies contiguous words while ignoring separators.
   - **Dual-Lookup System**: Each potential phrase is checked against both original and normalized dictionary entries to capture different formatting scenarios.

### Solution Code
```python
import re
import collections.abc

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    normalized_dict = {}
    original_dict = {}

    for key, value in dictionary.items():
        # Normalize by replacing non-alphanumeric separators with space and lowercase
        normalized_key = re.sub(r'\W+', ' ', key).strip().lower()
        original_key = key.lower()
        
        normalized_dict[normalized_key] = value
        original_dict[original_key] = value
    
    return {'normalized_dict': normalized_dict, 'original_dict': original_dict}

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    def is_separator(token):
        return not re.search(r'[a-zA-Z0-9_]', token)
    
    annotated = [(t, set()) for t in tokens]
    n = len(annotated)
    
    for i in range(n):
        for L in range(1, n - i + 1):
            current_tokens = tokens[i:i+L]
            non_sep = []
            
            # Extract non-separator tokens and lowercase them
            for t in current_tokens:
                if not is_separator(t):
                    non_sep.append(t.lower())
            
            if not non_sep:
                continue
            
            # Handle raw (concatenated) phrase check
            raw = ''.join(non_sep)
            if raw in dictionary_index['original_dict']:
                for idx in range(i, i+L):
                    annotated[idx][1].add(dictionary_index['original_dict'][raw])
            
            # Handle normalized (spaced) phrase check
            norm = ' '.join(non_sep)
            if norm in dictionary_index['normalized_dict']:
                for idx in range(i, i+L):
                    annotated[idx][1].add(dictionary_index['normalized_dict'][norm])
    
    return annotated
```

### Key Features
- **Case Insensitivity**: All dictionary lookups are performed in lowercase.
- **Two-Tier Matching**: Checks both concatenated words and normalized phrases.
- **Efficient Setup**: Preprocessing structures allow constant-time lookups during annotation.
- **Comprehensive Coverage**: Handles single words, compound phrases, nested phrases, and overlapping matches as required by the problem constraints.
