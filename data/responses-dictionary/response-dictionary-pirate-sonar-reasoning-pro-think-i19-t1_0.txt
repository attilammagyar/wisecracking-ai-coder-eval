## **Solution Overview**

1. **Dictionary Normalization**:  
   Converts all dictionary entries to lowercase and removes non-alphanumeric characters. This ensures case insensitivity and separator tolerance for compounds like "AAA BBB" matching "AAA, BBB" or "AAA*BBB".

2. **Individual Token Checks**:  
   For each token, its normalized form is checked against the dictionary. Matches add the corresponding identifier.

3. **Compound Phrase Detection**:  
   For each token position (`i`), the algorithm slides backward to form potential compounds by concatenating word tokens (ignoring separators). When a valid compound is found, all tokens in its span (including separators) are annotated.

    """Build a normalized index from a dictionary for fast lookup, ignoring case and non-alphanumeric characters."""
    index = {'lower_to_id': {}}
    for key, value in dictionary.items():
        normalized = ''.join(c.lower() for c in key if c.isalnum())
        index['lower_to_id'][normalized] = value
    return index

                for k in range(j, i + 1):
                    annotations[k].add(entry_id)
    
    return [(tokens[i], annotations[i]) for i in range(len(tokens))]
