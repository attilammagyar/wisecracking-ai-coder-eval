```python
from collections.abc import Mapping
from typing import Iterable, Tuple, Set, Any

def build_dictionary_index(dictionary: Mapping[str, Any]) -> tuple:
    """
    Preprocesses the dictionary into normalized keys and tracks maximum phrase length.
    """
    norm_dict = {}
    max_len = 0
    for key, value in dictionary.items():
        # Normalize: lowercase, remove non-alphanumeric characters (treat as separators)
        norm_key = ''.join([c.lower() for c in key if c.isalnum()])
        if norm_key:
            norm_dict.setdefault(norm_key, set()).add(value)
            max_len = max(max_len, len(norm_key))
    return {"index": norm_dict, "max_length": max_len}

def annotate(tokens: Iterable[str], index_data: Any) -> Iterable[Tuple[str, Set]]:
    """
    Annotates tokens by checking all possible spans for matching phrases.
    """
    annotations = [set() for _ in tokens]
    # Unpack index data
    norm_dict, max_len = index_data["index"], index_data["max_length"]
    
    for start in range(len(tokens)):
        for end in range(start, min(start + max_len + 1, len(tokens))):
            # Build normalized phrase for tokens[start:end]
            phrase = []
            for token in tokens[start:end]:
                word_part = ''.join([c.lower() for c in token if c.isalnum()])
                if word_part:
                    phrase.append(word_part)
            normalized = ''.join(phrase)
            
            # Check dictionary match
            if normalized in norm_dict:
                entry_ids = norm_dict[normalized]
                # Annotate all tokens in the span
                for idx in range(start, end):
                    annotations[idx].update(entry_ids)
    
    return [(token, ann) for token, ann in zip(tokens, annotations)]
```

**How This Works**  
1. **Normalization**: Dictionary entries are lowercased and stripped of non-alphanumeric characters, stored with entry IDs.  
2. **Span Checking**: For each token, we check spans up to the dictionary's longest phrase length.  
3. **Phonological Matching**: Tokens in a span form a phrase if their union (ignoring separators) matches a normalized key.  
4. **Overlapping Matches**: All matching spans contribute entry IDs to involved tokens, allowing multiple annotations per token.  

**Key Optimizations**  
- Uses **consistent normalization** (lowercase + filters) to handle case/separator variations.  
- Limits span length to the longest dictionary entry, reducing unnecessary checks.  
- **O(n * max_phrase_length**)** time complexity balances simplicity and efficiency for typical language learning scenarios.
