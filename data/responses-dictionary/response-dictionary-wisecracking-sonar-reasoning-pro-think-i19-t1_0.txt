**Problem Understanding**:  
We need a text annotation algorithm for language learners that:
- Marks each *word token* with its dictionary entry (individually and as part of compounds)
- Handles case insensitivity and variable separators (spaces, commas, symbols)
- Prioritizes inner separators in compounds but ignores leading/trailing ones
- Manages overlapping/nested compounds

---

**Solution Strategy**
1. **Dictionary Normalization**:  
   Convert each entry to lowercase, remove non-alphanumeric separators, and split into words. Store these normalized forms in a dictionary for quick lookups.

   Example:  
   `"AAA BBB"` → `normalize → "aaa bbb"`  
   `"black,swan"` → `normalize → "black swan"`

2. **Span-Based Annotation**  
   For every possible text span:
   - Collect words across contiguous tokens (ignoring non-word separators)
   - Normalize spans to see if they match dictionary entries
   - If matched, annotate *all tokens in the span* (including separators)

3. **Individual Token Check**  
   After span checks, validate individual tokens against the dictionary:
   - Normalize each token to its lowercase word form
   - Annotate if present in the dictionary

**Implementation**

```python
import re
from collections.abc import Iterable

def build_dictionary_index(dictionary: dict) -> dict:
    """Builds a normalized index for efficient dictionary lookups"""
    entry_strings = {}
    max_length = 0  # Track maximum word count in entries

    for key, value in dictionary.items():
        # Normalize: lowercase + split on non-word characters + join with spaces
        normalized = ' '.join(filter(None, re.split(r'\W+', key.lower()))).strip()
        if normalized:
            entry_strings[normalized] = value
            max_length = max(max_length, len(normalized.split()))
    
    return {'entry_strings': entry_strings, 'max_length': max_length}

def annotate(tokens: Iterable[str], dictionary_index: dict) -> Iterable[tuple[str, set]]:
    """Core annotation logic handling compounds and individual tokens"""
    entry_strings = dictionary_index['entry_strings']
    max_length = dictionary_index['max_length']
    num_tokens = len(tokens)
    annotations = [set() for _ in range(num_tokens)]

    # 1. Check all possible compound spans first
    for start in range(num_tokens):
        for end in range(start, num_tokens):
            words = re.findall(r'\w+', tokens[end].lower())
            normalized = ' '.join(words)
            if normalized in entry_strings:
                identifier = entry_strings[normalized]
                for i in range(start, end + 1):
                    annotations[i].add(identifier)
            # Additional logic to prevent unnecessary checks
            if end - start + 1 > max_length:
                break

    # 2. Check individual tokens with normalization
    for i, token in enumerate(tokens):
        parts = re.findall(r'\w+', token.lower())
        if parts:
            normalized = " ".join(parts)
            if normalized in entry_strings:
                annotations[i].add(entry_strings[normalized])

    return [(token, set(annots)) for token, annots in zip(tokens, annotations)]
```
