### Approach
The solution involves two main components:
1. **Dictionary Indexing**: 
   - Normalize dictionary entries to handle case insensitivity.
   - Separate entries into single words and compound phrases.
   - Store single words in a dictionary for O(1) lookups.
   - Store compound phrases as concatenated strings, preserving their order while ignoring separators.

2. **Annotation Algorithm**:
   - For each token, check if it matches a single-word entry.
   - For each token, check all possible sequences (up to maximum compound phrase length) to see if they form a valid compound phrase.
   - Annotate all tokens in valid sequences, including any separators between words.

This approach ensures that both single words and compound phrases are identified efficiently while handling variable separators.

### Solution Code
```python
import re
from collections.abc import Iterable, Set

def build_dictionary_index(dictionary: Iterable) -> object:
    normalized = {}
    for key, value in dictionary.items():
        lower_key = key.lower()
        if lower_key not in normalized:
            normalized[lower_key] = value

    single_words = {}
    multi_word_entries = {}
    max_word_count = 0

    for key, value in normalized.items():
        words = re.findall(r'\w+', key)
        word_count = len(words)
        if word_count > max_word_count:
            max_word_count = word_count
        if word_count == 1:
            if words[0] in single_words:
                raise ValueError(f"Duplicate single-word entry '{words[0]}'")  # Assuming no duplicates
            single_words[words[0]] = value
        else:
            if word_count < 1:
                continue  # Skip entries with no words
            concatenated = ''.join(words)
            if concatenated in multi_word_entries:
                multi_word_entries[concatenated].add(value)
            else:
                multi_word_entries[concatenated] = {value}

    return {
        'single_words': single_words,
        'multi_word_entries': multi_word_entries,
        'max_word_count': max_word_count
    }

def annotate(tokens: Iterable[str], dictionary_index: object) -> Iterable[tuple[str, Set]]:
    single_words = dictionary_index['single_words']
    multi_word_entries = dictionary_index['multi_word_entries']
    max_word_count = dictionary_index['max_word_count']
    
    annotations = [set() for _ in tokens]
    
    for i in range(len(tokens)):
        token = tokens[i]
        # Check single-word
        if re.match(r'^\w+$', token):
            lower_token = token.lower()
            if lower_token in single_words:
                annotations[i].add(single_words[lower_token])

        # Check multi-word sequences
        word_positions = []
        j = i
        while j < len(tokens):
            if re.match(r'^\w+$', tokens[j]):
                word_positions.append((j, tokens[j].lower()))
                if len(word_positions) >= max_word_count:
                    break
            j += 1
        
        for k in range(1, len(word_positions) + 1):
            if k > max_word_count:
                break
            concatenated = ''.join([p[1] for p in word_positions[:k]])
            if concatenated in multi_word_entries:
                entry_ids = multi_word_entries[concatenated]
                end_j = word_positions[k-1][0]
                for pos in range(i, end_j + 1):
                    annotations[pos].update(entry_ids)

    return [(tokens[i], annotations[i]) for i in range(len(tokens))]
```

### Explanation
1. **Dictionary Indexing**:
   - **Normalization**: Convert all keys to lowercase to handle case insensitivity.
   - **Single Words**: Store words in a dictionary for quick lookups.
   - **Compound Phrases**: Split phrases into word components, concatenate them into a single string, and store in a set for O(1) validation.

2. **Annotation**:
   - **Single-Word Check**: Directly match each token against the single-word dictionary.
   - **Compound Phrase Check**: For each token, collect up to `max_word_count` words and check concatenated strings against the compound phrase index. Annotate all tokens in valid sequences.

This approach ensures efficient lookups while handling overlapping phrases and variable separators, meeting all specified requirements.
