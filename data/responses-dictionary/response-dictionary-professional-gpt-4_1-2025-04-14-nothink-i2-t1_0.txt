### Dictionary Index Structure

For case-insensitive lookup, we canonicalize all tokens to lowercase.

### Normalization

We can use Python's `str.isalnum()` for word pieces and treat non-alnum runs as separators.

But, as shown in the tests, sometimes dictionary phrases use commas as separators and tokens use asterisk/space, so we must allow matching with *any* sequence of separator tokens between words. Thus, our trie should not contain separator nodes per se, but instead, at word boundaries, allow for "any number of successive separator tokens", skipping them as long as they're present (but remembering their token indexes for later annotation if a match occurs).

Thus, the matching logic for a phrase:
- Accepts any run of separator tokens in the token list as the boundary between words, no matter what separators appear in the dictionary.

- advance while matching successive tokens to phrase trie nodes, allowing multiple separators between word nodes.

Also, for each individual token, if it's a word token (i.e., matches a phrase of length one), annotate it directly if present in the dictionary.

# Helper: Split a phrase or token list into alternating word/non-word
def _split_phrase_to_tokens(phrase):
    """
    Split a string into alternating runs of word and non-word tokens,
    preserving the order. Lowercases words.
    """
    import re
    # Words: contiguous alphanum
    # Separators: contiguous non-alphanum
    tokens = []
    for m in re.finditer(r'\w+|\W+', phrase, flags=re.UNICODE):
        t = m.group(0)
        if t.isalnum():
            tokens.append(t.lower())
        else:
            tokens.append(t)
    return tokens

    __slots__ = ('children', 'entry_id')
    def __init__(self):

    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases. The index is a (trie, set of single-word lookups).
    """

    # For fast single-word lookup:
    single_word = {}

    # The phrase trie (skip over any separator tokens at match time)
    root = _TrieNode()

    for phrase_str, entry_id in dictionary.items():
        phrase_tokens = _split_phrase_to_tokens(phrase_str)

        # Build trie path; only word tokens are trie keys, separators are just separators
        words = []
        types = []  # True for word, False for sep
        for t in phrase_tokens:
            types.append(t.isalnum())
            words.append(t.lower() if t.isalnum() else t)

        # For single-word entries: must be a single word token (not a separator)
        if len(words) == 1 and types[0]:
            single_word[words[0]] = entry_id

        # We'll only store word nodes in the trie, and treat any non-word tokens as "skip any separators"
        trie_cur = root
        i = 0

            if i == N:

            trie_cur = trie_cur.children[w]
            i += 1
        trie_cur.entry_id = entry_id  # Mark phrase end

    return (root, single_word)
