**Solution Overview**

The solution employs a two-step approach to efficiently annotate tokens based on dictionary entries:

1. **Dictionary Index Construction**  
   Normalize dictionary entries by converting to lowercase and replacing all non-alphabetic characters with spaces. This creates a consistent format for lookup. Entries are stored with their IDs, and we track the maximum length of any entry to limit phrase checking spans.

2. **Annotation Algorithm**  
   For each token, check all possible phrases ending at its position, starting from the longest possible matches (down to individuals). Phrases must start/end with word tokens (non-separators) to exclude leading/trailing punctuation. Each matching phrase annotates all tokens within it.

**Code Implementation**  
```python
import re
from collections.abc import Mapping, Iterable

def build_dictionary_index(dictionary: Mapping) -> object:
    entry_map = {}
    max_length = 0
    for key, value in dictionary.items():
        normalized = re.sub(r'[^\w]', ' ', key.lower()).strip()
        normalized = ' '.join(normalized.split())
        entry_map[normalized] = value
        word_count = len(normalized.split())
        if word_count > max_length:
            max_length = word_count
    return {'entries': entry_map, 'max_length': max_length}

def annotate(tokens: Iterable[str], dictionary_index: object) -> Iterable[tuple[str, Iterable]]:
    entries = dictionary_index['entries']
    max_length = dictionary_index['max_length']
    n = len(tokens)
    annotations = [set() for _ in tokens]

    for i in range(n):
        # Annotate single-word match if applicable
        if tokens[i].isalpha():
            lower_token = tokens[i].lower()
            if lower_token in entries:
                annotations[i].add(entries[lower_token])

        # Check phrases ending at current word
        start_j = max(0, i - max_length + 1)
        for j in range(i, start_j - 1, -1):
            if not (tokens[j].isalpha() and tokens[i].isalpha()):
                continue
            phrase = []
            for k in range(j, i + 1):
                token = tokens[k]
                phrase.append(token.lower() if token.isalpha() else ' ')
            phrase_str = ' '.join(phrase)
            phrase_str = ' '.join(phrase_str.split())
            if phrase_str in entries:
                annotations[j].add(entries[phrase_str])
                annotations[i].add(entries[phrase_str])
                # Annotate middle tokens if applicable
                if j < i:
                    middle_tokens = range(j + 1, i)
                    if middle_tokens:  # Blanket add all in phrase
                        for k in middle_tokens:
                            annotations[k].add(entries[phrase_str])

    return [(t, s) for t, s in zip(tokens, annotations)]
```

**Explanation & Justification**  
1. **Normalization**  
   Dictionary entries are cleaned to lowercase with non-alphabetic chars replaced by spaces. This handles varied separators (e.g., "Château" vs "Chateau").

2. **Max Length Optimization**  
   By storing the longest entry length, we limit phrase checks to feasible spans, improving efficiency without missing potential matches.

3. **Phrase Validation**  
   Only phrases containing at least two word tokens (with optional internal punctuation) are considered valid. This prevents over-annotation of leading/trailing punctuation in multi-word entries.

4. **Bidirectional Annotation**  
   Matches automatically annotate all tokens within the phrase span, ensuring proper handling of both individual words and compound expressions. Middle punctuation receives annotations without creating false positives for standalone separators.

This approach successfully handles case insensitivity, varying separators, and overlapping compound phrases while maintaining O(n^2) worst-case complexity suitable for educational texts.
