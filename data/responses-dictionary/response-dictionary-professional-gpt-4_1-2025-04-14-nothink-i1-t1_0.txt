## Core Ideas

### 1. **Phrase Matching and Case Insensitivity**
- Dictionary lookups must be case-insensitive.
- Both single words and compounds/phrases must be discovered, regardless of token boundaries and separator variations (e.g., one phrase may be "black swan event", token stream may be: ["black", " ", "swan", " ", "event"]).

### 2. **Efficient Phrase Lookup**
- Any dictionary phrase, broken into tokens (words and separators), may match **spans of tokens** in the input.
- For efficiency, use a **Trie** (prefix tree) to represent all dictionary phrases. This allows greedy left-to-right exploration of matches, efficiently supporting multiple and overlapping matches.

### 3. **Token Normalization**
- Case-fold all dictionary entries and input tokens to lower-case at indexing/matching time.
- When inserting phrases into the trie, split each phrase into normalized **dictionary tokens** (words and separators), specifically preserving all non-word separators.

### 4. **Separator Insensitivity in Phrase Matching**
- Word separators (typically whitespace, but also other punctuation and formatting tokens) in dictionary phrases and in token streams may differ.
- We interpret "separator-insensitive": *allow any gap(s) of any word separator tokens between phrase-words*, so that, e.g., 'AAA, BBB' matches ['AAA', ' ', '*', 'BBB'].
- Thus, when splitting a dictionary phrase, treat runs of non-word characters as a single separator token.
- In the input tokens, classify each as `is_word` or not (for lookahead and matching).

### 5. **Annotation Logic**
- If a span of tokens matches a dictionary phrase, all **internal tokens** of that span (excluding leading or trailing external separators) are annotated with the phrase's entry (including inner separators).
- Multiple, even overlapping, annotations are allowed.
- Individual tokens that match as single words/entries receive those entries.

## Implementation Details

### **Dictionary Indexing: Trie Construction**

1. Normalize (lowercase) all dictionary entries.
2. Split each phrase in the dictionary into dictionary tokens:
   - Use a regular expression to separate words and separators.
   - E.g., "AAA, BBB" -> ["AAA", ",", " ", "BBB"]
3. In the trie, each node is a dict: key is dictionary token (word or separator), values are nested nodes. If a phrase ends at a node, store the dictionary's entry/meaning in a set at that node (`terminals`).
4. Remember the maximum phrase length (in tokens) for fast lookahead later.

### **Annotation Algorithm**

1. For input, for each token, record:
   - The token itself.
   - Its normalized (lowercased) value.
   - Whether it is a word or not (based on `str.isalnum()`).
2. For every starting position in the token list:
   - Attempt to walk the trie as far as possible (up to `max_phrase_length` tokens ahead), matching sequences of tokens.
   - For a match, annotate the **internal tokens** (excluding surrounding separators) with the entry.
   - Allow multiple overlapping phrases.
   - Crucially, treat different separator tokens in the stream and in the phrase as matching, as long as both are separators.
   - *We must not match across non-separator tokens, i.e., don't skip words to match separators in the phrase.*
3. Also, for each token, if it's a word and matches a dictionary entry as a single word, annotate it.

import collections.abc
import re

def _split_into_dict_tokens(text):
    # Split text into tokens: contiguous word or non-word spans.
    # E.g. "AAA, BBB" -> ["AAA", ", ", "BBB"]
    # But we also want each dictionary *token* to align to how the input is tokenized.
    # Use a regex that splits on *either* contiguous alphanumeric or contiguous non-alphanumeric
    # (including spaces and punctuations as separate tokens).
    tokens = []
    for match in re.finditer(r'\w+|[^\w]+', text, re.UNICODE):
        tokens.append(match.group(0))
    return tokens

def _is_word_token(token):
    # Heuristic: if it contains at least one alphanumeric character, call it a word
    return any(c.isalnum() for c in token)

class TrieNode:
    __slots__ = ['children', 'terminals']
    def __init__(self):
        self.children = dict()    # str -> TrieNode
        self.terminals = set()    # dictionary entry IDs that end here

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index (tries) for fast lookup of words and compound phrases.
    """
    # The trie will be built over *normalized* tokens only (casefolded).
    # We also gather the single-token dictionary for fast lookup.
    root = TrieNode()
    single_token_lookup = dict()  # normalized token -> set of entry IDs
    max_phrase_len = 1

    # Preprocess each dictionary entry
    for phrase, entry_id in dictionary.items():
        tokens = _split_into_dict_tokens(phrase.casefold())
        if not tokens:
            continue
        # Single token entries
        if len(tokens) == 1:
            single_token_lookup.setdefault(tokens[0], set()).add(entry_id)
        # Insert phrase into the trie
        node = root
        for tok in tokens:
            if tok not in node.children:
                node.children[tok] = TrieNode()
            node = node.children[tok]
        node.terminals.add(entry_id)
        if len(tokens) > max_phrase_len:
            max_phrase_len = len(tokens)

    index = {
        'trie': root,
        'single_token': single_token_lookup,
        'max_phrase_len': max_phrase_len,
    }
    return index

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.
    """
    tokens = list(tokens)  # Realize iterator
    N = len(tokens)
    # Preprocess tokens for normalization and word status
    norm_tokens = [t.casefold() for t in tokens]
    is_word = [_is_word_token(t) for t in tokens]

    # The output: for each token, a set of dictionary entries (as IDs)
    annots = [set() for _ in range(N)]

    # 1. Single token annotation pass
    single_token_dict = dictionary_index['single_token']
    for i, n_tok in enumerate(norm_tokens):
        if n_tok in single_token_dict:
            annots[i].update(single_token_dict[n_tok])

    # 2. Phrase (trie) annotation pass
    trie_root = dictionary_index['trie']
    maxlen = dictionary_index['max_phrase_len']

    i = 0
    while i < N:
        j = i
        node = trie_root
        n_segs = 0
        while j < N and n_segs < maxlen:
            t = norm_tokens[j]

            # Try to follow the trie by matching:
            #   - exact token (if exists)
            #   - if not exact, and both the current trie edge and token are non-word, match all separators together.
            found = False
            for edge in node.children:
                # Either an exact token match
                if edge == t:
                    child = node.children[edge]
                    found = True
                    match_type = 'exact'
                    break
                # Or both are separators (non-word tokens): match (as "wildcard" for separators)
                elif not _is_word_token(edge) and not is_word[j]:
                    child = node.children[edge]
                    found = True
                    match_type = 'sep'
                    break
            if not found:
                break
            node = child
            j += 1
            n_segs += 1
            if node.terminals:
                # We have a dictionary phrase match
                # Know that phrase runs from i (inclusive) to j (exclusive)
                start, end = i, j
                # Identify the internal tokens to annotate:
                # - Skip any **leading/trailing** separators surrounding the phrase
                s = start
                e = end - 1
                # Find first word token in [start, end-1], call it ws
                while s <= e and not is_word[s]:
                    s += 1
                # Find last word token in [start, end-1], call it we
                while e >= s and not is_word[e]:
                    e -= 1
                # Annotate only tokens in s..e (inclusive), but also annotate any **separators inside** (as per rules)
                for pos in range(start, end):
                    # If pos==s..e always annotate (it's in the central phrase, separator or not)
                    # If pos is a word separator outside [s..e], do NOT annotate
                    if pos >= s and pos <= e:
                        annots[pos].update(node.terminals)
            # Continue searching for longer phrase matches (to allow for longest/overlapping matches)
        i += 1

    return list(zip(tokens, annots))
