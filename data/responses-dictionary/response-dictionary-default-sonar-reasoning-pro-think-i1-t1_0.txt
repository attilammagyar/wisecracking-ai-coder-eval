To solve this problem, we need to develop an efficient text annotation algorithm that handles both individual words and compound phrases, considering varying word separators and different tokenization schemes. Here's the structured approach:

### Algorithm Design
**1. Index Construction (build_dictionary_index):**
- **Normalization:** Convert all dictionary entries to lowercase and replace non-alphanumeric characters with spaces. This ensures case insensitivity and handles different separators.
- **Indexing:** Store normalized phrases alongside single words for quick lookup.

**2. Annotation Process (annotate):**
- **Single-Word Check:** Directly match each token against the normalized index.
- **Phrase Detection:** Identify sequences of words (word runs) potentially forming compound phrases. Use a sliding window approach within these runs to check all possible spans, normalizing each span and verifying against the index.

**3. Word Run Identification:**
- **Splitting Tokens:** Group tokens into sequences (word runs) that may form phrases, excluding leading/trailing separators.
- **Span Checking:** For each word run, generate all possible spans that start and end with words, normalizing them to check for compound phrases in the index.

import re
from collections.abc import Iterable

def build_dictionary_index(dictionary: Iterable[tuple[str, int]]) -> dict:
    index = {}
    for key, value in dictionary:
        # Normalize dictionary keys: lowercase + replace non-alphanumerics with spaces
        normalized = ' '.join(re.split(r'[^a-zA-Z0-9]', key.lower()))
        index[normalized] = value
    return index

def annotate(tokens: Iterable[str], dictionary_index: dict) -> Iterable[tuple[str, set]]:  
    # Precompute lowercased tokens for single-word checks
    lower_tokens = [t.lower() for t in tokens]
    
    # Prepare annotations
    annotations = [set() for _ in range(len(tokens))]
    
    # Check single-word matches
    for i, token in enumerate(tokens):
        lower = lower_tokens[i]
        if lower in dictionary_index:
            annotations[i].add(dictionary_index[lower])
    
    # Split into word runs (tracking original indices)
    word_runs = []
    current_run = []
    in_run = False
    for idx, token in enumerate(tokens):
        if any(c.isalpha() for c in token):  # Basic word detection
            if in_run:
                current_run.append(idx)
            else:
                in_run = True
                current_run = [idx]
        else:
            if in_run:
                current_run.append(idx)
            else:
                pass
    
    if in_run:
        word_runs.append(current_run)
    
    # Process each word run for compound phrases
    for run_indices in word_runs:
        word_pos = [i for i in run_indices if any(c.isalpha() for c in tokens[i])]  # Identify word positions within run
        
        # Check all possible word-to-word spans within the run
        for i in range(len(word_pos)):  
            for j in range(i, len(word_pos)):  
                start = word_pos[i]
                end = word_pos[j]
                span = tokens[start:end+1]
                normalized = ' '.join([t.lower() for t in span if any(c.isalpha() for c in t)})
                
                if normalized in dictionary_index:
                    entry = dictionary_index[normalized]
                    for k in range(start, end+1):
                        if k < len(annotations):
                            annotations[k].add(entry)
    
    return [(tokens[i], annotations[i]) for i in range(len(tokens))]
