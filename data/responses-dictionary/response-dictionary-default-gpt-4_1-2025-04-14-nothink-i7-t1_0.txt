### Main Ideas and Algorithm

Let's break down the requirements and derive a practical solution:

#### 1. **Token Annotation Objective**

We must annotate each token with all *dictionary entries* that match:
- The token alone,
- Any compound phrase it takes part in (including compounds with intervening separators).

#### 2. **Dictionary Indexing**

Performance is key, so lookup must be efficient for:
- Single token,
- Compounds of up to N tokens (phrases of any length in the dictionary),
- Allowing for variable and *any* separator tokens between words,
- **Case-insensitivity**.

**Chosen Strategy:**  
We will preprocess the dictionary into a trie (prefix tree) where:
- Each **matching segment** (token, separator) is normalized:
    - Words become lowercased,
    - All separators are stored as a "placeholder" (to normalize possible separator mismatches).
- Each trie node collects set(s) of entry ids for dictionary phrases that end at that point.

When matching, word tokens and separator tokens are distinguished on-the-fly.

#### 3. **Normalization**

- Words: `[a-zA-Z0-9]+` — lowered.
- Separators: Any non-word token (may include punctuation, spaces, Markdown chars, etc).
- **Separator normalization**:
    - In the dictionary, any sequence of non-word chars between words is just a "SEP" placeholder.
    - In token stream, consecutive non-word tokens (separators) are collectively considered as "SEP" for phrase matching, but for annotation, **all are annotated** (except leading/trailing).

#### 4. **Annotation Algorithm**

- For every position in the token sequence:
    - For every possible start of a compound phrase (ending at this token, up to max phrase length in dictionary):
        - Attempt to "walk" the trie backwards over the tokens, mapping word tokens to normalized words, separator tokens to "SEP",
            - Disallow a phrase that starts/ends with a separator (for proper leading/trailing logic).
        - For every match, annotate the relevant tokens:
            - For word tokens: always annotate if in the match.
            - For separator tokens: annotate only if not leading/trailing separator (i.e., if they're inner separators).
    - Also annotate single token dictionary matches (look up lowercased token).

- To make this efficient, we process matches forward but keep track (for each trie-op) of which tokens are "consumed" and "mapped".

#### 5. **Trie Construction**

- Each trie node is a dict mapping from normalized token type or "SEP" to the next node.
- Each node holds a set of entry ids for complete phrases ending here.
- We also record `max_depth` (max phrase length) for phrase matching bounds.

#### 6. **Efficiency Considerations**

- Maximal matching: We allow overlapping, nested, and repeated phrase matching (all matches counted).
- O(N * M) — N: tokens; M: max phrase length.

import collections.abc
import re

_WORD_RE = re.compile(r'\w+', flags=re.UNICODE)

def _is_word(token):
    # A word is at least one alphanumeric/underscore character.
    return _WORD_RE.fullmatch(token) is not None

def _normalize_token(token):
    # Lowercase words, else treat as separator (for dictionary and matching purposes).
    return token.lower() if _is_word(token) else 'SEP'

class DictTrieNode:
    __slots__ = ['children', 'entries']
    def __init__(self):
        self.children = dict()
        self.entries = set()

def build_dictionary_index(dictionary: collections.abc.Mapping):
    """
    Build a trie-based, separator-normalized index from the dictionary.
    """
    root = DictTrieNode()
    max_phrase_len = 1  # Record max words in any phrase, for efficient matching.

    for phrase, entry in dictionary.items():
        tokens = []
        buf = ''
        for char in phrase:
            if _is_word(char):
                buf += char
            else:
                if buf:
                    tokens.append(buf)
                    buf = ''
                tokens.append(char)
        if buf:
            tokens.append(buf)

        # Now normalize sequence of tokens as list of (word/separator) segments:
        norm = []
        i = 0
        while i < len(tokens):
            if _is_word(tokens[i]):
                norm.append(tokens[i].lower())
                i += 1
            else:
                # Merge consecutive separators as one 'SEP':
                while i < len(tokens) and not _is_word(tokens[i]):
                    i += 1
                norm.append('SEP')
        # Remove leading/trailing 'SEP'
        if norm and norm[0] == 'SEP':
            norm = norm[1:]
        if norm and norm and norm[-1] == 'SEP':
            norm = norm[:-1]

        # Remember length in words (for later max len to limit matching).
        wordcount = sum(1 for t in norm if t != 'SEP')
        max_phrase_len = max(max_phrase_len, wordcount)

        # Insert into the trie:
        node = root
        for t in norm:
            if t not in node.children:
                node.children[t] = DictTrieNode()
            node = node.children[t]
        node.entries.add(entry)

    return {'root': root, 'max_phrase_len': max_phrase_len, 'dict': {k.lower(): v for k, v in dictionary.items()}}

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object):
    """
    Annotate tokens with entries from the dictionary, using a trie-based search for phrases.
    """
    # Convert tokens to list for multiple passes.
    tokens = list(tokens)
    annotated = [set() for _ in tokens]
    tokens_norm = [_normalize_token(tok) for tok in tokens]
    is_word = [_is_word(tok) for tok in tokens]

    root = dictionary_index['root']
    max_phrase_len = dictionary_index['max_phrase_len']
    word_dict = dictionary_index['dict']

    # Build list of word token positions for phrase windowing
    word_positions = [i for i, w in enumerate(is_word) if w]

    N = len(tokens)
    # For every possible start position (window start), only on word tokens
    for w_start in range(len(word_positions)):
        # Do not go beyond phrase-word-length
        for w_end in range(min(w_start+1, len(word_positions)), min(w_start+max_phrase_len, len(word_positions))+1):
            tok_start = word_positions[w_start]
            tok_end = word_positions[w_end-1]
            # window = tokens[tok_start:tok_end+1], may include separators between them

            # Build normalized list that matches trie token stream:
            norm_seq = []
            prev_tok = tok_start
            for i in range(tok_start, tok_end+1):
                if i > prev_tok:
                    # Insert SEP between each two word tokens if separated
                    if any(not is_word[j] for j in range(prev_tok+1, i)):
                        norm_seq.append('SEP')
                norm_seq.append(tokens[i].lower())
                prev_tok = i

            # Now traverse trie:
            node = root
            matched = True
            for n in norm_seq:
                if n in node.children:
                    node = node.children[n]
                else:
                    matched = False
                    break
            if matched and node.entries:
                # To ensure dictionary phrase separators generalize to multiple consecutive separators
                # between words, check that all tokens between tok_start and tok_end are accounted for
                # (allow separators of any kind and count them as "inner" if between words).
                # Map which tokens in window are word/separator
                # Need to annotate:
                # - all word tokens within tok_start .. tok_end
                # - all separator tokens between, but not before first word nor after last word
                # start: tok_start, end: tok_end
                # Mark tokens to annotate for this match:
                for i in range(tok_start, tok_end+1):
                    if is_word[i]:
                        annotated[i].update(node.entries)
                # Inner separators: tokens between start-end, non-word, not at endpoints.
                for i in range(tok_start+1, tok_end):
                    if not is_word[i]:
                        annotated[i].update(node.entries)
    # Annotate individual word matches (case insensitive)
    for i, tok in enumerate(tokens):
        if is_word[i]:
            entry = word_dict.get(tok.lower())
            if entry is not None:
                annotated[i].add(entry)

    # Return as requested: (token, set) pairs per input
    return [(token, anns) for token, anns in zip(tokens, annotated)]
