### Explanation of the Algorithm

The solution addresses the text annotation problem by breaking it down into two main parts: an offline indexing step (`build_dictionary_index`) and an online annotation step (`annotate`). The core idea is to handle two distinct types of dictionary entries efficiently:
1.  **Solid Words**: Single words or compound words written without spaces (e.g., "swan", "blackswan").
2.  **Phrases**: Sequences of two or more words separated by spaces or punctuation (e.g., "black swan", "once in a blue moon").

To achieve this, the `build_dictionary_index` function constructs a composite index object containing two specialized data structures:

*   **A dictionary for Solid Words (`solid_word_index`)**: This is a simple Python `dict` that maps a normalized (lowercased) solid word to a `set` of its associated dictionary IDs. This provides `O(1)` average-time complexity for lookups.
*   **A Trie for Phrases (`phrase_trie_root`)**: A Trie (prefix tree) is used to store the sequences of words that form phrases. Each path from the root to a node represents a sequence of words, and nodes corresponding to the end of a valid phrase store the relevant dictionary IDs. This structure allows for efficient searching of multiple phrases simultaneously. For example, after processing the token "black", we can instantly check for all phrases that begin with "black swan", "black cat", etc.

The `annotate` function then uses this pre-built index to find all possible matches in the input token stream. For each possible starting position in the token list, it performs two types of searches:

1.  **Solid Word Matching**: It attempts to form compound words by concatenating consecutive "word" tokens (e.g., `["black", "swan"]` -> `"blackswan"`). It checks each concatenation against the `solid_word_index`. This search stops as soon as a non-word (separator) token is encountered.

2.  **Phrase Matching**: It traverses the `phrase_trie_root` using the sequence of "word" tokens from the input. It gracefully skips over any separator tokens, allowing phrases like `"AAA, BBB"` in the dictionary to match token sequences like `["AAA", " ", "*", "BBB"]`.

When a match of either type is found, the corresponding dictionary IDs are added to the annotation sets for all tokens that are part of the match. This includes the words themselves and any separators between them for phrases. This process is repeated for every possible starting token, ensuring that all overlapping and nested matches are found and correctly annotated.

This dual-structure approach provides a clean and efficient solution that correctly handles all the specified requirements, including case-insensitivity, variations in separators, and different types of compound entries.

import collections.abc
import re

# A dedicated class to hold the prepared index structures. This is an
# implementation detail and is not exposed to the caller, who will receive it
# as an `object`.
class _DictionaryIndex:
    """A container for the processed dictionary data structures."""
    def __init__(self):
        # Trie for multi-word phrases.
        # e.g., {"black swan": 4} -> root -> 'black' -> 'swan' (value={4})
        self.phrase_trie_root = {'children': {}, 'value': set()}
        
        # Simple dict for single solid words, including concatenated ones.
        # e.g., {"black": 1, "blackswan": 2} -> {'black': {1}, 'blackswan': {2}}
        self.solid_word_index = collections.defaultdict(set)

# Helper to identify tokens that are words. Based on the tests, words are
# alphanumeric. Everything else is a separator.
_WORD_PATTERN = re.compile(r'^[a-zA-Z0-9]+$')
def _is_word(token: str) -> bool:
    """Checks if a token is a word component (alphanumeric)."""
    return _WORD_PATTERN.match(token) is not None

# Helper to normalize dictionary keys into sequences of word components.
# e.g., "black, swan" -> ["black", "swan"]; "blackswan" -> ["blackswan"]
_SPLIT_WORDS_PATTERN = re.compile(r'[a-zA-Z0-9]+')
def _normalize_key(key: str) -> list[str]:
    """Converts a dictionary key string into a list of normalized words."""
    return _SPLIT_WORDS_PATTERN.findall(key.lower())

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    Parameters:
        dictionary: Mapping strings (keys) to meanings (values).
    """
    index = _DictionaryIndex()

    for key, value in dictionary.items():
        normalized_words = _normalize_key(key)
        
        if not normalized_words:
            continue

        if len(normalized_words) == 1:
            # This is a single "solid" word (e.g., "cat", "houseboat").
            index.solid_word_index[normalized_words[0]].add(value)
        else:
            # This is a multi-word phrase (e.g., "black cat").
            node = index.phrase_trie_root
            for word in normalized_words:
                if word not in node['children']:
                    node['children'][word] = {'children': {}, 'value': set()}
                node = node['children'][word]
            node['value'].add(value)

    return index

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.

    Parameters:
        dictionary_index:   A dictionary index created by build_dictionary_index()
        tokens:             The tokens to be annotated.

    Return:
        annotated_tokens:   A list containing (token, annotations) pairs for each token in tokens.
    """
    if not isinstance(dictionary_index, _DictionaryIndex):
        raise TypeError("dictionary_index is not of the expected type.")

    token_list = list(tokens)
    num_tokens = len(token_list)
    annotated_tokens = [(token, set()) for token in token_list]

    for i in range(num_tokens):
        # 1. Match solid words (single tokens or concatenations of tokens).
        # This handles cases like "swan" and "blackswan" from ["black", "swan"].
        current_concat = ""
        consumed_token_indices = []
        for j in range(i, num_tokens):
            token = token_list[j]
            if not _is_word(token):
                # Concatenated words cannot have separators between them.
                break
            
            current_concat += token
            consumed_token_indices.append(j)
            
            normalized_concat = current_concat.lower()
            if normalized_concat in dictionary_index.solid_word_index:
                values = dictionary_index.solid_word_index[normalized_concat]
                for token_idx in consumed_token_indices:
                    annotated_tokens[token_idx][1].update(values)

        # 2. Match multi-word phrases using the Trie.
        # A phrase in the text must start with a word token.
        if not _is_word(token_list[i]):
            continue

        node = dictionary_index.phrase_trie_root
        last_word_idx = -1
        for j in range(i, num_tokens):
            token = token_list[j]
            if _is_word(token):
                normalized_word = token.lower()
                if normalized_word in node['children']:
                    node = node['children'][normalized_word]
                    last_word_idx = j
                    if node['value']:
                        # A valid phrase ending here has been found.
                        values = node['value']
                        # Annotate all tokens from the phrase start `i` to the
                        # end of its last word `last_word_idx`.
                        for k in range(i, last_word_idx + 1):
                            annotated_tokens[k][1].update(values)
                else:
                    # No further match possible along this phrase path.
                    break
            # If the token is a separator, we just skip it, allowing the
            # phrase match to continue across it.
    
    return annotated_tokens
