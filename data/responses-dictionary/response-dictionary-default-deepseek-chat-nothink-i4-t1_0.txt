### Understanding the Problem

We need to annotate tokens from a text with dictionary entries, considering both individual words and compound phrases. The key challenges are:

1. **Case Insensitivity**: Dictionary lookups should be case-insensitive.
2. **Compound Phrases**: Need to detect multi-token phrases in the dictionary.
3. **Separator Handling**: Inner separators in phrases should be annotated, but leading/trailing ones should not.
4. **Efficiency**: The solution should efficiently handle lookups, especially for compound phrases.

### Solution Approach

1. **Dictionary Index**:
   - Normalize dictionary keys to lowercase for case-insensitive lookup.
   - Build a trie (prefix tree) for efficient phrase lookup. Each node represents a word or separator, and leaf nodes contain the dictionary entry IDs.
   - Additionally, maintain a simple set of individual words for quick single-word lookups.

2. **Annotation Algorithm**:
   - For each token, check if it's a word (non-separator). 
   - For words, look up individual matches and potential compound phrases starting at that position.
   - For compound phrases, slide a window over subsequent tokens, building a normalized phrase string and checking against the trie.
   - Collect all matching dictionary entries for each token.

### Implementation

```python
import collections.abc
from typing import Dict, Set, List, Tuple, Any

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    The index consists of:
    - A case-insensitive word set for individual words.
    - A trie for compound phrases, where each path represents a phrase.
    """
    word_set = set()
    trie = {}

    for phrase, entry_id in dictionary.items():
        # Normalize phrase to lowercase and split into words/separators
        normalized_phrase = phrase.lower()
        words = normalized_phrase.split()
        
        if len(words) == 1:
            # Single word entry
            word_set.add((words[0], entry_id))
        else:
            # Compound phrase entry: add to trie
            current = trie
            for word in words:
                if word not in current:
                    current[word] = {}
                current = current[word]
            # Mark the end of the phrase with its entry_id
            if None not in current:
                current[None] = set()
            current[None].add(entry_id)

    return {
        'word_set': word_set,
        'trie': trie,
    }

def is_word_token(token: str) -> bool:
    """Check if a token is a word (as opposed to a separator)."""
    return any(c.isalnum() for c in token)

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[Tuple[str, Set]]:
    """
    Annotate tokens with entries from the dictionary.

    For each token, check:
    - Individual word matches.
    - All possible compound phrases starting at that token.
    """
    tokens = list(tokens)  # Allow multiple passes
    annotated_tokens = []
    word_set = dictionary_index['word_set']
    trie = dictionary_index['trie']

    for i in range(len(tokens)):
        token = tokens[i]
        annotations = set()

        # Check individual word match
        normalized_token = token.lower()
        for word, entry_id in word_set:
            if normalized_token == word:
                annotations.add(entry_id)

        # Check compound phrases starting at this token
        if is_word_token(token):
            current_node = trie
            j = i
            current_phrase_words = []
            while j < len(tokens) and current_node is not None:
                current_token = tokens[j]
                normalized_current_token = current_token.lower()
                
                if not is_word_token(current_token):
                    # Separator: must match a separator in the trie
                    if ' ' in current_node:
                        current_node = current_node[' ']
                        current_phrase_words.append(' ')
                    else:
                        current_node = None
                else:
                    # Word: must match a word in the trie
                    if normalized_current_token in current_node:
                        current_node = current_node[normalized_current_token]
                        current_phrase_words.append(normalized_current_token)
                    else:
                        current_node = None
                
                if current_node is not None and None in current_node:
                    # Found a complete phrase match
                    annotations.update(current_node[None])
                
                j += 1

        annotated_tokens.append((token, annotations))

    return annotated_tokens
```

### Explanation

1. **Dictionary Index**:
   - **Word Set**: Stores individual words and their entry IDs for O(1) lookups.
   - **Trie**: Each path in the trie represents a compound phrase. Nodes are words or separators, and leaf nodes (marked by `None`) store the entry IDs.

2. **Annotation**:
   - For each token, check if it matches any individual word in the dictionary.
   - For potential compound phrases, traverse the trie while consuming subsequent tokens:
     - If the token is a word, follow the corresponding trie node.
     - If it's a separator, follow the separator node (represented by `' '`).
     - If a leaf node is reached, add its entry IDs to the annotations of all tokens in the phrase.

This approach efficiently handles both individual words and compound phrases, with case insensitivity and proper separator handling. The trie ensures that compound phrase lookups are proportional to the phrase length, not the dictionary size.
