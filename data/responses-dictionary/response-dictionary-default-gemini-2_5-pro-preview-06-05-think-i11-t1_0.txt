### Solution Explanation

The text annotation problem requires finding all occurrences of dictionary words and phrases within a tokenized text, handling various complexities like case-insensitivity, flexible separators, and misalignments between token boundaries and dictionary word boundaries.

My solution approaches this with a two-stage process: an indexing stage and an annotation stage.

#### 1. Dictionary Indexing (`build_dictionary_index`)

To enable fast lookups, the raw dictionary is first converted into a more efficient data structure. A **Trie** (also known as a prefix tree) is the ideal choice here. It allows for searching all dictionary entries simultaneously in a single pass over the input tokens.

The indexing process works as follows:
1.  **Normalization**: Each dictionary key (word or phrase) is normalized before being inserted into the trie. This involves:
    *   Converting the key to lowercase to ensure case-insensitive matching.
    *   Splitting the key into a sequence of "word parts" based on non-alphanumeric characters. For example, `"black-swan event"` is normalized to the sequence `("black", "swan", "event")`. This makes the matching process robust against variations in separators (e.g., spaces, hyphens, commas).
2.  **Trie Construction**: The normalized sequences of word parts are inserted into the trie. Each node in the trie represents a prefix, and edges are labeled with word parts. The final node for each dictionary entry is marked as a "terminal" node and stores the corresponding dictionary value.

This pre-processing step creates an index that is optimized for the matching logic in the annotation phase.

#### 2. Annotation Algorithm (`annotate`)

The annotation function iterates through the input tokens and uses the dictionary index to find all matches.

The core of the algorithm is a search function that is executed for every token position. This ensures that all possible matches, including overlapping and nested ones, are found. For instance, in "AAA BBB CCC", it will find both "AAA BBB" and "BBB CCC".

The search logic at each starting position works like this:

1.  **Iterative Search**: A stack-based, iterative search is employed to traverse the trie. This avoids deep recursion and efficiently explores all potential phrase matches starting from the current position. A stack item stores the current `(trie_node, token_cursor, phrase_start_index)`.

2.  **Chunking and Normalization**: The algorithm intelligently handles the potential mismatch between tokens and dictionary words. It works by:
    *   Grouping consecutive "word-like" tokens (those containing at least one alphanumeric character) into a "chunk".
    *   This chunk is then normalized using the same logic as the dictionary keys (lowercase, split by non-alphanumerics). For example, if tokens are `["black-", "swan"]`, they form a chunk `"black-swan"`, which normalizes to `("black", "swan")`.
    *   This normalized sequence of parts is then used to traverse the trie from the current node.

3.  **Matching and Annotation**:
    *   As the algorithm successfully traverses the trie, it checks if any node it visits is a terminal node.
    *   If a match is found, all tokens that form the phrase—from the first word of the phrase to the last—are annotated with the dictionary entry. This correctly includes inner separators (e.g., the space in "black swan") while excluding leading or trailing ones.
    *   The search continues from that point to find longer, nested phrases (e.g., finding "black swan event" after matching "black swan").

This systematic approach ensures all requirements are met efficiently and correctly, providing a robust solution for the text annotation task.

import collections.abc
import re

#
# Helper functions
#

def _is_word_like(token: str) -> bool:
    """
    A token is considered word-like if it contains at least one alphanumeric character.
    This helps distinguish words from pure separators like " ", "*", or ".".
    """
    return any(c.isalnum() for c in token)


def _split_phrase(phrase: str) -> list[str]:
    """
    Splits a phrase into a list of normalized "word" parts.
    Normalization involves lowercasing and splitting by non-alphanumeric characters.
    For example, "Black-Swan Event" becomes ["black", "swan", "event"].
    """
    # Split by any sequence of one or more non-alphanumeric characters.
    parts = re.split(r'[^a-zA-Z0-9]+', phrase.lower())
    # Filter out empty strings that can result from splitting.
    return [part for part in parts if part]


#
# Main implementation
#

class _DictionaryIndex:
    """A helper class to store the dictionary trie."""
    _TERMINAL_KEY = '_v_'

    def __init__(self, dictionary: collections.abc.Mapping):
        self.trie = {}
        for key, value in dictionary.items():
            parts = _split_phrase(key)
            if not parts:
                continue

            node = self.trie
            for part in parts:
                node = node.setdefault(part, {})
            node.setdefault(self._TERMINAL_KEY, set()).add(value)


def _search_and_annotate(
    start_token_idx: int,
    tokens: list[str],
    index: _DictionaryIndex,
    annotated_tokens: list[tuple[str, set]]
):
    """
    Searches for all dictionary entries starting from a given token index
    and updates annotations accordingly.
    """
    n = len(tokens)
    # Stack for iterative traversal of matching possibilities.
    # Item: (trie_node, token_cursor, phrase_start_token_idx).
    stack = [(index.trie, start_token_idx, -1)]

    while stack:
        trie_node, token_cursor, phrase_start_idx = stack.pop()

        # Find the start of the next chunk of word-like tokens, skipping separators.
        chunk_start_cursor = token_cursor
        while chunk_start_cursor < n and not _is_word_like(tokens[chunk_start_cursor]):
            chunk_start_cursor += 1

        if chunk_start_cursor >= n:
            continue

        current_phrase_start_idx = phrase_start_idx if phrase_start_idx != -1 else chunk_start_cursor
        
        chunk_str = ""
        for j in range(chunk_start_cursor, n):
            if not _is_word_like(tokens[j]):
                break  # A separator ends the current word-like chunk.

            chunk_str += tokens[j]
            chunk_end_cursor = j
            
            parts = _split_phrase(chunk_str)
            if not parts:
                continue

            # Traverse the trie with the parts from the current chunk.
            match_node = trie_node
            is_match_possible = True
            for part in parts:
                if part in match_node:
                    match_node = match_node[part]
                else:
                    is_match_possible = False
                    break
            
            if is_match_possible:
                # We found a path in the trie. Check if it's a valid dictionary entry.
                if index._TERMINAL_KEY in match_node:
                    values = match_node[index._TERMINAL_KEY]
                    # Annotate all tokens from the start of the phrase to the end of the current chunk.
                    for k in range(current_phrase_start_idx, chunk_end_cursor + 1):
                        annotated_tokens[k][1].update(values)
                
                # If the trie path can be extended, search for longer phrases.
                if any(key != index._TERMINAL_KEY for key in match_node):
                    stack.append((match_node, chunk_end_cursor + 1, current_phrase_start_idx))

# Public API
#

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    Parameters:
        dictionary: Mapping strings (keys) to meanings (values).
    """
    return _DictionaryIndex(dictionary)


def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.

    Parameters:
        dictionary_index:   A dictionary index created by build_dictionary_index()
        tokens:             The tokens to be annotated.

    Return:
        annotated_tokens:   A list containing (token, annotations) pairs for each token in tokens.
    """
    if not isinstance(dictionary_index, _DictionaryIndex):
        raise TypeError("dictionary_index is not of the expected type.")

    token_list = list(tokens)
    n = len(token_list)
    if n == 0:
        return []
        
    annotated_tokens = [(token, set()) for token in token_list]

    for i in range(n):
        _search_and_annotate(i, token_list, dictionary_index, annotated_tokens)

    return annotated_tokens
