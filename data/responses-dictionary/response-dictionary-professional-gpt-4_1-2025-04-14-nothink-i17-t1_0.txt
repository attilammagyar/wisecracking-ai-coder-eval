## Main Ideas

### 1. **Normalization**
- **Case:** All dictionary keys and token comparisons are lowercased.
- **Separators:** For compound phrases, all separators (spaces, punctuation) in dictionary keys are normalized to a single space so tokenization differences won't break matches.

### 2. **Dictionary Index Structure**
- **Single-word entries:** Simple `dict` mapping normalized word to set of ids.
- **Compound phrases:** Use a **trie** (prefix tree) where each node is a normalized dictionary word or separator, so phrase matching is efficient.
- **Max phrase length:** Store the maximum number of words in a dictionary phrase for windowed matching.

### 3. **Token Parsing**
- **Token classification:** For each token, determine "word" (letters/digits, etc.) or "separator" (spaces, punctuation, etc.).
- **Windowed matching:** For every position in the token stream, try to match longest possible dictionary phrase (starting at that position), skipping leading separators and trailing ones as needed, and only annotate inner separators.

### 4. **Annotation Algorithm**
- For each token, collect:
  - The dictionary id(s) for matching individual tokens, if any.
  - For every windowed match (compound phrase), annotate all tokens in the phrase (except leading and trailing separators) with the id.
  - Allow overlapping matches (so tokens may be involved in several matches).

### 5. **Efficiency**
- Trie traversal for compounds, so windowed match is O(# tokens * max_phrase_len).
- All annotation is in-place and does not need excessive memory allocations.

import collections.abc

def _is_word_token(token):
    # Heuristic: token is a word if it contains at least one alphanumeric
    return any(c.isalnum() for c in token)

def _normalize_token(token):
    return token.lower()

def _normalize_dict_phrase(phrase):
    """
    Lowercase and normalize all separators to a single space between words (and strip).
    So e.g. "AAA, *** BBB" -> "aaa bbb"
    """
    import string
    parts = []
    last_was_space = False
    for c in phrase.lower():
        if c.isalnum():
            parts.append(c)
            last_was_space = False
        else:
            if not last_was_space:
                parts.append(' ')
                last_was_space = True
    # Remove leading/trailing/multiple spaces.
    norm = ''.join(parts)
    return ' '.join(norm.strip().split())

class _TrieNode:
    __slots__ = ('children', 'dict_ids')
    def __init__(self):
        # word -> _TrieNode
        self.children = {}
        # dictionary ids for this leaf (can be set for non-leaf if phrase is a prefix of another phrase)
        self.dict_ids = set()

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.
    """
    # Single-words: {normalized_token: set(dictionary_ids)}
    word_dict = collections.defaultdict(set)
    # Compound phrase trie
    trie_root = _TrieNode()
    # This will help optimize phrase matching
    max_phrase_len = 1

    for key, dict_id in dictionary.items():
        norm_entry = _normalize_dict_phrase(key)
        words = norm_entry.split()  # words here only, never separators
        if len(words) == 1:
            word_dict[words[0]].add(dict_id)
        elif len(words) > 1:
            # Insert into trie
            node = trie_root
            for w in words:
                if w not in node.children:
                    node.children[w] = _TrieNode()
                node = node.children[w]
            node.dict_ids.add(dict_id)
            max_phrase_len = max(max_phrase_len, len(words))

    return {
        # For single tokens
        'word_dict': word_dict,
        # For phrase matches
        'trie_root': trie_root,
        'max_phrase_len': max_phrase_len,
    }

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary (single words and compound phrases).
    """
    tokens = list(tokens)
    n = len(tokens)
    result = [(token, set()) for token in tokens]
    # Helper for separating word tokens from separators
    word_token_flags = [_is_word_token(t) for t in tokens]
    norm_tokens = [_normalize_token(t) for t in tokens]

    # Single-word annotation
    word_dict = dictionary_index['word_dict']
    for idx, (is_word, norm_tok) in enumerate(zip(word_token_flags, norm_tokens)):
        if is_word:
            if norm_tok in word_dict:
                result[idx][1].update(word_dict[norm_tok])

    # Compound phrase annotation using the trie
    trie_root = dictionary_index['trie_root']
    max_phrase_len = dictionary_index['max_phrase_len']

    idx = 0
    while idx < n:
        # To handle all overlapping/embedded matches, 
        # at every position, try *all* windows from len=1 to max_phrase_len
        for window_len in range(1, max_phrase_len+1):
            # window = tokens[idx : idx+window_len tokens]
            # Step 1: get the word tokens and their positions
            words = []
            word_positions = []
            k = idx
            while len(words) < window_len and k < n:
                if word_token_flags[k]:
                    words.append(norm_tokens[k])
                    word_positions.append(k)
                k += 1
            if len(words) != window_len:
                continue  # Not enough tokens left for this window
            # Step 2: attempt a trie match
            node = trie_root
            found = True
            for w in words:
                if w in node.children:
                    node = node.children[w]
                else:
                    found = False
                    break
            if found and node.dict_ids:
                # Step 3: Identify the phrase span in tokens:
                # from word_positions[0] to word_positions[-1], includes all tokens in between
                phrase_start = word_positions[0]
                phrase_end = word_positions[-1]
                # According to the requirements:
                #  - annotate every token in the window, including separators in-between,
                #  - but do NOT annotate leading/trailing separators bordering the phrase!
                # That is: annotate only tokens from phrase_start to phrase_end, inclusive.
                # But do not annotate if the current window does not begin bordering a word token
                for pos in range(phrase_start, phrase_end+1):
                    # Annotate:
                    result[pos][1].update(node.dict_ids)
        idx += 1

    # Now fix leading and trailing separators: 
    # For every phrase match above, it only annotates tokens inside window [phrase_start, phrase_end]
    # This already solves the "do not annotate leading/trailing separators" requirement because
    # the logic above only includes the span from first word to last word of phrase.
