Here's a solution designed to handle text annotation for language learning with efficient compound phrase detection:

---

### Approach

**Core Idea:**  
Use a **trie data structure** to pre-process dictionary entries, allowing quick validation of possible compound phrases. For annotation, iteratively check all possible token subsequences to match against the trie, then propagate annotations to all involved tokens.

**Key Steps:**

1. **Preprocessing Dictionary Entries**  
   Convert entries to lowercase, replace non-alphanumeric characters with spaces, and split into token sequences. Store in a trie for efficient sequence matching.

2. **Annotation Process**  
   For each possible token subsequence:
   - Normalize to handle case sensitivity and separators
   - Check against trie for dictionary matches
   - Annotate all tokens in matching subsequences

**Efficiency:**  
- **Trie Storage:** O(m) where m is total dictionary tokens stored
- **Annotation Check:** O(n²) per token list (manageable for typical texts)

def build_dictionary_index(dictionary):
    """Build a trie-based index for dictionary entries"""
    trie = {}
    for key, value in dictionary.items():
        normalized = key.lower()
        normalized = ' '.join([c if c.isalnum() else ' ' for c in normalized])

from collections.abc import Iterable

def annotate(tokens: Iterable[str], dictionary_index) -> Iterable[tuple[str, set]]:
    """Annotate tokens using pre-built dictionary index"""
    if not tokens or not dictionary_index:
        return [(t, set()) for t in tokens]
    
    annotations = [set() for _ in tokens]
    n = len(tokens)
    
    for i in range(n):
        for j in range(i, n):
            substring = ''.join(tokens[i:j+1])
            normalized = ' '.join([c if c.isalnum() else ' ' for c in substring.lower()])
            normalized = ' '.join(normalized.split())
            tokens_in_sub = normalized.split()
            if not tokens_in_sub:
                continue
            
            current = dictionary_index
            matched = True
            for token in tokens_in_sub:
                if token not in current:
                    matched = False
                    break
                current = current[token]
            
            if matched and 'value' in current:
                entry_id = current['value']
                for k in range(i, j+1):
                    annotations[k].add(entry_id)
    
    return [(t, s) for t, s in zip(tokens, annotations)]

   - Normalize the substring to lowercase/standard spacing
   - Check against trie for exact token sequence matches
   - Annotate all tokens in matching sequence with dictionary ID

3. **Efficiency Considerations**  
   - Trie allows O(k) time per sequence check (k = sequence length)
   - Only non-separator tokens contribute to sequence matching
   - Annotations collected using sets to handle overlaps

This approach handles nested phrases, overlapping sequences and separator variations while maintaining readable implementation.
