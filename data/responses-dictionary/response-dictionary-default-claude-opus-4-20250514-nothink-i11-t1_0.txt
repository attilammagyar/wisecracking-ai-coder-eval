## Main Ideas

### Data Structure
I'll use a **trie (prefix tree)** to store normalized dictionary entries. Each node represents a character, and paths from root to marked nodes represent dictionary entries. This allows efficient prefix matching and finding all possible matches starting from any position.

The trie will store:
- Normalized words (lowercase, with words in phrases separated by single spaces)
- At terminal nodes: the set of dictionary entry IDs for that word/phrase

### Normalization
- Convert to lowercase for case-insensitive matching
- For compound phrases: extract words, normalize separators to single spaces

### Lookup Algorithm
1. For each starting position in the token sequence:
   - Try to match against the trie by traversing tokens
   - Skip over non-word tokens when matching compound phrases
   - Collect all matches (individual words and phrases)

2. For each token, aggregate all dictionary entries from:
   - Matches where the token is part of an individual word
   - Matches where the token is part of a compound phrase (including separators)

### Key Insights
- A token is considered a "word token" if it contains at least one alphanumeric character
- When matching compound phrases, we skip non-word tokens but still include them in the annotation
- Leading/trailing separators are excluded from phrase annotations

class TrieNode:
    def __init__(self):
        self.children = {}
        self.entry_ids = set()

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, word, entry_id):
        node = self.root
        for char in word:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.entry_ids.add(entry_id)
    
    def search_prefix(self, text, start_pos):
        """Return all matches starting at start_pos with their end positions."""
        matches = []
        node = self.root
        pos = start_pos
        
        while pos < len(text) and node:
            char = text[pos]
            if char in node.children:
                node = node.children[char]
                pos += 1
                if node.entry_ids:
                    matches.append((pos, node.entry_ids))
            else:
                break
        
        return matches

    return any(c.isalnum() for c in token)

            current_word.append(char.lower())
        else:
            if current_word:
                words.append(''.join(current_word))
                current_word = []
    
    if current_word:
        words.append(''.join(current_word))
    
    return ' '.join(words) if len(words) > 1 else (words[0] if words else '')
