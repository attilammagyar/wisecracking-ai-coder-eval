Main ideas

- Normalize the dictionary: treat a “word” as a contiguous sequence of letters. We lower-case everything for case-insensitive matching. Dictionary keys are split into words by stripping non-letter characters:
  - If a key yields exactly one word, it is a single-word entry. It must match a single token, or a concatenation of multiple adjacent word tokens with no separators between them (e.g., "AAABBB" matching ["AAA", "BBB"]).
  - If a key yields two or more words, it is a multi-word phrase entry. It must match a consecutive sequence of word tokens, while allowing any separators between those words. Inner separators are annotated, but not any leading or trailing separators around the phrase.

- Index structure:
  - single_words: dict word -> set(ids) for fast O(1) lookup of single-word entries (including concatenated runs of tokens).
  - phrase_trie: a trie keyed by words (not characters) for multi-word phrases. Each trie node holds a set of ids that end at that node. This enables linear-time matching over the sequence of word tokens while skipping separators in the original token stream.

- Annotation algorithm:
  1) Build an is_word mask for tokens and a parallel list of lower-cased tokens. Also collect the sequence of word tokens (lower-cased) and their original token indices.
  2) Multi-word phrases: scan the word sequence with the phrase trie. On every match, annotate all tokens from the first matched word’s token index to the last matched word’s token index, inclusive. This naturally includes inner separators and excludes outer ones.
  3) Single-word entries (including compound words with no separators): scan maximal runs of consecutive word tokens (no separators in between). For each run, try all start/end positions and check whether the concatenation of tokens[start..end] matches an entry in single_words. Annotate the participating tokens if it matches.

This satisfies all requirements, including case-insensitivity, separator insensitivity for multi-word phrases, no midtoken matches, and proper separator annotation.

import collections.abc

# Internal helpers and data structures

def _is_word_token(token: str) -> bool:
    # Treat tokens made solely of letters as "word" tokens
    # (case-insensitive logic will lower elsewhere).
    return token.isalpha()


def _extract_words(text: str) -> list[str]:
    # Split by non-letters; lower-cased; ignore empty pieces.
    words = []
    cur = []
    for ch in text:
        if ch.isalpha():
            cur.append(ch.lower())
        else:
            if cur:
                words.append("".join(cur))
                cur = []
    if cur:
        words.append("".join(cur))
    return words


class _TrieNode:
    __slots__ = ("children", "ids")

    def __init__(self):
        self.children = {}  # word -> _TrieNode
        self.ids = set()    # set of entry ids ending here


class _DictionaryIndex:
    __slots__ = ("single_words", "phrase_root")

    def __init__(self, single_words, phrase_root):
        self.single_words = single_words  # dict[str, set]
        self.phrase_root = phrase_root    # _TrieNode root


def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    Parameters:
        dictionary: Mapping strings (keys) to meanings (values).
    """
    single_words = {}  # word -> set(ids)
    phrase_root = _TrieNode()

    for key, entry_id in dictionary.items():
        words = _extract_words(key)
        if not words:
            continue
        if len(words) == 1:
            w = words[0]
            bucket = single_words.get(w)
            if bucket is None:
                bucket = set()
                single_words[w] = bucket
            bucket.add(entry_id)
        else:
            # Insert into word-level trie
            node = phrase_root
            for w in words:
                child = node.children.get(w)
                if child is None:
                    child = _TrieNode()
                    node.children[w] = child
                node = child
            node.ids.add(entry_id)

    return _DictionaryIndex(single_words=single_words, phrase_root=phrase_root)


def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.

    Parameters:
        dictionary_index:   A dictionary index created by build_dictionary_index()
        tokens:             The tokens to be annotated.

    Return:
        annotated_tokens:   A list containing (token, annotations) pairs for each token in tokens.
    """
    # Materialize tokens; we need random access and lengths.
    toks = list(tokens)
    n = len(toks)

    # Prepare outputs (sets for each token).
    ann = [set() for _ in range(n)]

    idx = dictionary_index  # type: ignore
    single = idx.single_words
    root = idx.phrase_root

    # Classify tokens and prepare lower-cased copies.
    is_word = [_is_word_token(t) for t in toks]
    lower_toks = [t.lower() for t in toks]

    # Build the sequence of word tokens and their original token indices.
    word_seq = []        # list[str]
    word_pos = []        # list[int] original token index for each word in word_seq
    for i, (wflag, lt) in enumerate(zip(is_word, lower_toks)):
        if wflag:
            word_seq.append(lt)
            word_pos.append(i)

    # 1) Multi-word phrase matches (ignore separators between words).
    # Scan the word sequence using the word-level trie.
    W = len(word_seq)
    for start in range(W):
        node = root
        widx = start
        while widx < W:
            w = word_seq[widx]
            node = node.children.get(w)
            if node is None:
                break
            if node.ids:
                t_start = word_pos[start]
                t_end = word_pos[widx]
                # Annotate all tokens from first matched word to last matched word inclusive.
                for ti in range(t_start, t_end + 1):
                    ann[ti].update(node.ids)
            widx += 1

    # 2) Single-word matches, including concatenations across adjacent word tokens with no separators.
    i = 0
    while i < n:
        if not is_word[i]:
            i += 1
            continue
        # Find maximal run [i..j] of consecutive word tokens (no separators).
        j = i
        while j + 1 < n and is_word[j + 1]:
            j += 1

        # For every start in this run, try all end >= start, checking concatenation against single-word map.
        for start in range(i, j + 1):
            s = ""
            for end in range(start, j + 1):
                s += lower_toks[end]
                ids = single.get(s)
                if ids:
                    for ti in range(start, end + 1):
                        ann[ti].update(ids)

        i = j + 1

    # Assemble final annotated tokens.
    annotated_tokens = [(toks[i], ann[i]) for i in range(n)]
    return annotated_tokens
