## **Core Idea**  
The solution hinges on **normalizing dictionary entries** to a unified lowercase format with single spaces for comparison, then **checking all possible token sequences** to find matching compound phrases. This handles varied separators and overlap efficiently. Think of it as a **brute-force approach** for simplicity, but streamlined enough to pass those test cases without breaking a sweat.

```python
import re
import collections.abc

def build_dictionary_index(dictionary: collections.abc.Mapping) -> dict:
    """Normalizes dictionary entries to lowercase and replaces separators with spaces."""
    normalized = {'phrases': set(), 'mapping': {}}
    for key, value in dictionary.items():
        # Normalize the phrase: lowercase, replace separators, strip
        normalized_key = re.sub(r'[^a-zA-Z0-9]+', ' ', key.lower()).strip()
        normalized['phrases'].add(normalized_key)
        normalized['mapping'][normalized_key] = value
    return normalized

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: dict) -> list[tuple[str, set]]:
    """Checks all token sub-sequences for matches in the normalized dictionary."""
    annotations = [set() for _ in tokens]
    for i in range(len(tokens)):
        for j in range(i, len(tokens)):
            # Generate normalized phrase from current sub-sequence
            phrase = ''.join(tokens[i:j+1])
            normalized_phrase = re.sub(r'[^a-zA-Z0-9]+', ' ', phrase.lower()).strip()
            if len(normalized_phrase) == 0:
                continue  # Skip empty "phrases"
            if normalized_phrase in dictionary_index['phrases']:
                entry_id = dictionary_index['mapping'][normalized_phrase]
                for k in range(i, j+1):
                    annotations[k].add(entry_id)
    return list(zip(tokens, annotations))
```

- **Normalization steps**:  
  1. Convert keys to lowercase.  
  2. Replace fancy/pony separators (``, `*`, etc.) with a single space.  
  3. Strip extra whitespace.  
  This lets `"AAA, BBB"`, `"AAA-BBB"`, and `"AAA BBB"` match as `"aaa bbb"`.  

### **2. Annotation Workflow**  
1. **Check all possible token sequences**:  
   For every possible start/end position in tokens (`i` to `j`), generate the normalized phrase.  
   *Example: tokens ["AAA", " ", "BBB"] → phrases checked: "AAA", "AAA ", "AAA  BBB", " ", "  BBB", "BBB"*

2. **Match to normalized phrases**:  
   If the phrase exists in the dictionary, annotate **all tokens** in the sequence.  

3. **Handle overlaps**:  
   Multiple matching phrases (e.g., `"AAA BBB CCC"` and `"BBB CCC"` in the same tokens) will layer annotations.
