Main ideas

- Normalize the dictionary once for fast lookups.
  - Case-insensitive: everything is lowercased.
  - Split dictionary keys into “words” by removing non-alphanumeric separators.
  - Store single-word entries in a hash map for O(1) lookup.
  - Store multi-word phrases in a trie keyed by word sequences, ignoring separators in the dictionary keys.

- Token classification
  - A token is a “word” if all its characters are alphanumeric (token.isalnum()).
  - All other tokens are separators (spaces, punctuation, Markdown markers, etc.).

- Token concatenation
  - Tokenization can be finer than the dictionary entries. For any position i, precompute all possible concatenations of consecutive word tokens starting at i until the next separator. These concatenations allow:
    - Matching single words that span multiple tokens (e.g., "AAABBB" matching ["AAA", "BBB"]).
    - Matching each word of a multi-word phrase when that word itself is split into multiple tokens.

- Matching rules
  - Single-word matches: for each (start, end) concatenation, if it’s a single-word dictionary entry, annotate all tokens from start to end (only word tokens; there are no separators inside).
  - Phrase matches: start only at word tokens. Match the first phrase word via concatenation; for each subsequent phrase word:
    - Require at least one separator token between words in the text.
    - Allow any number and any kinds of separators between words.
    - For each matched phrase suffix, annotate the entire continuous span from the first matched word token to the last matched word token, thus annotating only inner separators (never leading/trailing ones).

- Overlaps and nesting
  - Explore all valid matches (DFS over the phrase trie). Accumulate all dictionary IDs for each token in a set to support overlaps and nested phrases.

- No midtoken matches
  - We only concatenate whole tokens and never match within a token, so matches always end at a token boundary.

- Efficiency
  - Precompute concatenations once per start index (simple O(n^2) in the worst case over runs of word tokens).
  - Trie-based phrase matching prunes the search space quickly.
  - Only built-in libraries are used.

import collections.abc
import re
from typing import Dict, List, Tuple, Set, Iterable, Any


def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    The index contains:
      - single_words: dict[word -> set(ids)]
      - phrase_trie: trie over sequences of words (>=2 words)
        node = {"next": {word: node}, "out": set(ids)}
    """
    word_re = re.compile(r"[0-9A-Za-z]+")
    single_words: Dict[str, Set[Any]] = {}
    # Trie node: {"next": dict, "out": set}
    def new_node():
        return {"next": {}, "out": set()}

    phrase_root = new_node()

    def insert_phrase(words: List[str], value: Any) -> None:
        node = phrase_root
        for w in words:
            nxt = node["next"].get(w)
            if nxt is None:
                nxt = new_node()
                node["next"][w] = nxt
            node = nxt
        node["out"].add(value)

    for key, val in dictionary.items():
        words = word_re.findall(str(key).lower())
        if not words:
            # Ignore entries without any alphanumeric word
            continue
        if len(words) == 1:
            w = words[0]
            if w not in single_words:
                single_words[w] = set()
            single_words[w].add(val)
        else:
            insert_phrase(words, val)

    return {
        "single_words": single_words,
        "phrase_root": phrase_root,
    }


def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary using the index produced by build_dictionary_index().
    """
    toks: List[str] = list(tokens)
    n = len(toks)
    annotated: List[Set[Any]] = [set() for _ in range(n)]
    if n == 0:
        return []

    # Extract dictionary index
    single_words: Dict[str, Set[Any]] = dictionary_index["single_words"]
    phrase_root = dictionary_index["phrase_root"]

    # Classify tokens
    is_word: List[bool] = [t.isalnum() for t in toks]
    lower: List[str] = [t.lower() for t in toks]

    # Precompute all concatenations of consecutive word tokens starting at i
    # cat_cache[i] = list of (end_index, concatenated_lower)
    cat_cache: List[List[Tuple[int, str]]] = [[] for _ in range(n)]
    i = 0
    while i < n:
        if not is_word[i]:
            i += 1
            continue
        # Walk the run of consecutive word tokens
        j = i
        s = lower[i]
        cat_cache[i].append((i, s))
        j += 1
        while j < n and is_word[j]:
            s += lower[j]
            cat_cache[i].append((j, s))
            j += 1
        i = j  # continue from the first non-word (or end)

    # 1) Annotate single-word entries (including those spanning multiple tokens)
    for start in range(n):
        if not is_word[start]:
            continue
        for end, word_cat in cat_cache[start]:
            ids = single_words.get(word_cat)
            if ids:
                for k in range(start, end + 1):
                    annotated[k].update(ids)

    # 2) Annotate multi-word phrases using phrase trie (ignore dictionary separators)
    # DFS function: we have matched from 'start_idx' to 'last_end' and are at 'node'.
    def dfs_extend(node: dict, start_idx: int, last_end: int) -> None:
        # If current node ends a phrase (>=2 words by construction), annotate full span
        if node["out"]:
            ids = node["out"]
            for k in range(start_idx, last_end + 1):
                annotated[k].update(ids)

        # Require at least one separator between dictionary words
        sep_start = last_end + 1
        if sep_start >= n or is_word[sep_start]:
            return
        r = sep_start
        # Skip over one or more separators to the next word start
        while r < n and not is_word[r]:
            r += 1
        if r >= n:
            return

        # Try to match the next dictionary word starting at r (possibly spanning multiple word tokens)
        for end2, word2 in cat_cache[r]:
            child = node["next"].get(word2)
            if child is not None:
                dfs_extend(child, start_idx, end2)

    # Try every possible start (word tokens only)
    for start in range(n):
        if not is_word[start]:
            continue
        # First dictionary word starting at 'start' can span multiple word tokens
        for end1, word1 in cat_cache[start]:
            node1 = phrase_root["next"].get(word1)
            if node1 is not None:
                # We have matched the first phrase word; extend to 2nd and beyond (requires separators in-between)
                dfs_extend(node1, start, end1)

    return [(toks[i], annotated[i]) for i in range(n)]
