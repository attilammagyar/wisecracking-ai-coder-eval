3. **Phrases** - like "black swan" or "once in a blue moon" (with separators between words)

The trick be knowin' which type each entry be! If it has separators (spaces, punctuation) between words, it be a phrase. Otherwise, it be a word or compound word.

### The Matching Algorithm

Here be the clever part, ye scallywag:

1. **For phrases**: We match the sequence o' words, ignorin' what specific separators be between 'em. So "black swan" matches "black—swan" or "black * swan", aye!

2. **For words/compound words**: We match exact text (case-insensitive). So "AAABBB" matches when we concatenate ["AAA", "BBB"] together.

3. **All tokens in a match get annotated** - includin' the separators in the middle o' phrases (but not the ones at the start or end).

### The Implementation

Here be the code, written with the finest craftsmanship this side o' the Caribbean:

```python
import collections.abc
import re

def is_word_token(token):
    """Check if a token contains at least one word character."""
    return bool(re.search(r'\w', token))

def normalize_text(text):
    """Normalize text for case-insensitive comparison."""
    return text.lower()

def tokenize_entry(entry):
    """
    Analyze a dictionary entry to extract its words and type.
    Returns (words, is_phrase) where:
    - words is a list of normalized words
    - is_phrase is True if the entry contains separators between words
    """
    # Find all words in the entry
    word_matches = list(re.finditer(r'\w+', entry))
    
    if len(word_matches) == 0:
        return [], False
    
    words = [normalize_text(match.group()) for match in word_matches]
    
    # Check if it's a phrase (has separators between words)
    if len(word_matches) > 1:
        # Check if there are non-word characters between the first and last word
        first_end = word_matches[0].end()
        last_start = word_matches[-1].start()
        between = entry[first_end:last_start]
        is_phrase = bool(between)
    else:
        is_phrase = False
    
    return words, is_phrase

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    Parameters:
        dictionary: Mapping strings (keys) to meanings (values).
    """
    index = {
        'entries': []  # List of (pattern, value, is_phrase) tuples
    }
    
    for key, value in dictionary.items():
        words, is_phrase = tokenize_entry(key)
        if words:
            if is_phrase:
                # Store as a phrase pattern (list of words)
                pattern = words
            else:
                # Store as exact text pattern
                pattern = normalize_text(key)
            index['entries'].append((pattern, value, is_phrase))
    
    return index

def match_phrase(tokens, start_pos, pattern_words):
    """
    Try to match a phrase pattern starting at start_pos.
    Returns (match_found, end_pos) where end_pos is the last position of the match.
    """
    if not is_word_token(tokens[start_pos]):
        return False, -1
    
    word_count = 0
    current_pos = start_pos
    
    while current_pos < len(tokens) and word_count < len(pattern_words):
        if is_word_token(tokens[current_pos]):
            if normalize_text(tokens[current_pos]) != pattern_words[word_count]:
                return False, -1
            word_count += 1
            if word_count == len(pattern_words):
                return True, current_pos
        current_pos += 1
    
    return False, -1

def match_exact(tokens, start_pos, pattern_text):
    """
    Try to match exact text starting at start_pos.
    Returns (match_found, end_pos) where end_pos is the last position of the match.
    """
    # Try increasingly longer sequences
    for end_pos in range(start_pos, len(tokens)):
        concat = ''.join(tokens[start_pos:end_pos+1])
        if normalize_text(concat) == pattern_text:
            return True, end_pos
    
    return False, -1

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.

    Parameters:
        dictionary_index:   A dictionary index created by build_dictionary_index()
        tokens:             The tokens to be annotated.

    Return:
        annotated_tokens:   A list containing (token, annotations) pairs for each token in tokens.
    """
    tokens = list(tokens)
    n = len(tokens)
    
    # Initialize annotations for each token
    annotations = [set() for _ in range(n)]
    
    # Try to match patterns starting at each position
    for start_pos in range(n):
        for pattern, value, is_phrase in dictionary_index['entries']:
            if is_phrase:
                # Try to match phrase pattern
                match_found, end_pos = match_phrase(tokens, start_pos, pattern)
                if match_found:
                    # Annotate all tokens from start to end
                    for i in range(start_pos, end_pos + 1):
                        annotations[i].add(value)
            else:
                # Try to match exact pattern
                match_found, end_pos = match_exact(tokens, start_pos, pattern)
                if match_found:
                    # Annotate all tokens from start to end
                    for i in range(start_pos, end_pos + 1):
                        annotations[i].add(value)
    
    # Build result
    annotated_tokens = []
    for i, token in enumerate(tokens):
        annotated_tokens.append((token, annotations[i]))
    
    return annotated_tokens
```
