### Explanation of the Solution

The solution approaches the annotation problem by separating dictionary entries into two categories based on their structure, which allows for handling different matching requirements efficiently.

#### 1. Dictionary Indexing (`build_dictionary_index`)

To enable fast lookups, we first process the raw dictionary into a more structured index. This index is a dictionary containing two specialized maps:

*   **`words` map**: This stores dictionary entries that consist of a single, continuous string of alphanumeric characters, like `"word"` or `"compoundword"`. These are stored in lowercase to ensure case-insensitive matching. This map is used for separator-sensitive matching.
*   **`phrases` map**: This stores entries containing separators, like `"black swan"` or `"once-in-a-blue-moon"`. To handle variations in separators, these keys are normalized: we extract all word components (sequences of alphanumeric characters), convert them to lowercase, and join them with a single space. For example, both `"black, swan"` and `"black-swan"` would normalize to `"black swan"`. This map is used for separator-insensitive matching.

This two-map approach cleanly separates the logic for matching compound words (which cannot be broken by separators in the text) from phrases (where separators are flexible).

#### 2. Annotation Algorithm (`annotate`)

The annotation process iterates through all possible sequences of word tokens in the input text and attempts to match them against the pre-built dictionary index.

The core algorithm is as follows:

1.  First, it identifies all "word" tokens in the input, distinguishing them from separators like spaces or punctuation. A token is considered a word if it contains at least one alphanumeric character.
2.  It then iterates through every possible contiguous subsequence of these word tokens. For example, in a text with words `W1, W2, W3`, it would check `(W1)`, `(W1, W2)`, `(W1, W2, W3)`, then `(W2)`, `(W2, W3)`, and finally `(W3)`.
3.  For each subsequence, it performs two types of lookups:
    *   **Phrase Match**: It normalizes the subsequence by joining the lowercase word tokens with spaces and looks up the result in the `phrases` map of the index. If a match is found, all tokens in the original text spanning from the beginning of the first word to the end of the last word in the subsequence (including any separators in between) are annotated.
    *   **Word/Compound Match**: It checks if the original slice of tokens corresponding to the subsequence contains any separators. This systematic approach ensures that all possible matches are found, including overlapping and nested phrases. By processing all subsequences, it correctly populates the annotation sets for each token with all relevant dictionary entries.

import collections.abc
import re

def _is_word(token: str) -> bool:
    """
    Determines if a token is a "word" by checking for the presence of any
    alphanumeric character. This helps distinguish words from pure separators
    like " ", "*", or ".".
    """
    return any(c.isalnum() for c in token)


def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    The index is a dictionary containing two maps:
    - 'words': For dictionary entries that are single words or compound words
               without separators (e.g., "cat", "blackswan"). Keys are lowercased.
    - 'phrases': For dictionary entries that contain separators (e.g.,
                 "black swan", "once-in-a-lifetime"). Keys are normalized by
                 extracting word components, lowercasing them, and joining
                 with single spaces.

    This structure allows the annotation algorithm to efficiently handle
    different matching rules.

    Parameters:
        dictionary: Mapping strings (keys) to meanings (values).
    """
    phrase_map = {}
    word_map = {}

    for key, value in dictionary.items():
        # A key is treated as a phrase if it contains any non-alphanumeric
        # characters, which are assumed to be separators.
        if any(not c.isalnum() for c in key):
            # Normalize the phrase by finding all sequences of alphanumeric
            # characters, converting them to lowercase, and joining with spaces.
            word_parts = re.findall(r'[a-zA-Z0-9]+', key.lower())
            if word_parts:
                normalized_phrase = " ".join(word_parts)
                phrase_map[normalized_phrase] = value
        else:
            # The key is a single word or a compound word without separators.
            # It's stored lowercased in the word map.
            word_map[key.lower()] = value
            
    return {'phrases': phrase_map, 'words': word_map}


def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.

    The algorithm iterates through all possible contiguous subsequences of
    word tokens from the input text. For each subsequence, it attempts two
    types of matches against the dictionary index:

    1.  **Phrase Match**: The subsequence of word tokens is normalized (joined
        by spaces) and looked up in the 'phrases' map. This is insensitive to
        the original separators in the text. If a match is found, all tokens
        from the first word to the last word of the subsequence are annotated.

    2.  **Word/Compound Match**: The original token slice (including any
        separators) is concatenated and looked up in the 'words' map. This
        match is only valid if the token slice contains no separators,
        enforcing that compound words from the dictionary (e.g., "blackswan")
        are only matched by adjacent word tokens in the text (e.g., ["black", "swan"]).

    This dual-matching strategy handles single words, compound words, and
    phrases with varying separators, accommodating overlaps and nested structures.

    Parameters:
        dictionary_index: A dictionary index created by build_dictionary_index().
        tokens:           The tokens to be annotated.

    Return:
        annotated_tokens: A list containing (token, annotations) pairs for
                          each token in tokens.
    """
    tokens = list(tokens)
    if not tokens:
        return []

    annotated_tokens = [(token, set()) for token in tokens]
    
    # Pre-calculate which tokens are words to optimize inner loops.
    token_is_word = [_is_word(t) for t in tokens]
    # Get indices of word tokens, as matches can only start with a word.
    word_indices = [i for i, is_word in enumerate(token_is_word) if is_word]

    phrase_map = dictionary_index['phrases']
    word_map = dictionary_index['words']

    # Iterate through all possible start words for a match.
    for i in range(len(word_indices)):
        start_token_idx = word_indices[i]
        
        current_word_parts = []
        # Extend the match by including subsequent words.
        for j in range(i, len(word_indices)):
            end_word_idx = word_indices[j]
            current_word_parts.append(tokens[end_word_idx].lower())
            
            # This is the full slice of original tokens, including separators,
            # from the start word to the end word of the current candidate match.
            token_slice = tokens[start_token_idx : end_word_idx + 1]

            # 1. Check for a phrase match (separator-insensitive).
            phrase_key = " ".join(current_word_parts)
            if phrase_key in phrase_map:
                value = phrase_map[phrase_key]
                # Annotate all tokens within the phrase span.
                for k in range(start_token_idx, end_word_idx + 1):
                    annotated_tokens[k][1].add(value)

            # 2. Check for a word/compound match (separator-sensitive).
            # This match is only valid if the token slice has no separators.
            has_separator_in_slice = any(not token_is_word[k] for k in range(start_token_idx, end_word_idx + 1))
            
            if not has_separator_in_slice:
                word_key = "".join(t.lower() for t in token_slice)
                if word_key in word_map:
                    value = word_map[word_key]
                    for k in range(start_token_idx, end_word_idx + 1):
                        annotated_tokens[k][1].add(value)
                        
    return annotated_tokens
