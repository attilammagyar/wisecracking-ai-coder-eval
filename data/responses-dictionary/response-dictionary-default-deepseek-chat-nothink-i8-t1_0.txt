### Solution Explanation

#### Main Ideas
1. **Dictionary Index Construction**:
   - The dictionary needs to support two types of lookups: exact matches (for individual words) and phrase matches (for compound phrases).
   - For exact matches, we'll normalize the keys (case-insensitive) and store them in a dictionary.
   - For phrase matches, we'll build a **trie** (prefix tree) to efficiently find all possible phrases that start at a given position in the token sequence. The trie will store normalized versions of the dictionary keys, split into components (words or separators).

2. **Token Annotation**:
   - For each token in the input sequence, we'll first check for exact matches in the dictionary.
   - Then, we'll use the trie to find all possible compound phrases starting at the current token. For each phrase found, we'll annotate all tokens involved in the phrase.
   - The trie allows us to efficiently explore all possible phrase matches without redundant lookups.

#### Key Components
1. **Trie Structure**:
   - Each node in the trie represents a word or separator in a phrase.
   - Nodes store the dictionary entry IDs for phrases that end at that node.
   - The trie is built by splitting each dictionary key into components (words or separators) and inserting them into the trie.

2. **Normalization**:
   - All dictionary keys and tokens are normalized (lowercased) for case-insensitive matching.
   - Separators in phrases are treated uniformly (any sequence of non-word characters is considered a separator).

3. **Annotation Algorithm**:
   - For each token, check for exact matches.
   - Use the trie to find all phrases starting at the current token. For each phrase found, annotate all tokens in the phrase with the corresponding dictionary entry.
   - Skip leading and trailing separators when considering phrases.

#### Efficiency
- The trie ensures that phrase lookups are efficient (O(m) for a phrase of length m).
- Exact matches are O(1) per token.
- The overall complexity is O(n * m), where n is the number of tokens and m is the maximum phrase length in the dictionary.

### Implementation
```python
import collections.abc
import re
from typing import Dict, Set, List, Tuple, Any

# Helper function to check if a token is a word (as opposed to a separator)
def is_word_token(token: str) -> bool:
    return bool(re.fullmatch(r'\w+', token))

# Trie node for phrase lookup
class TrieNode:
    __slots__ = ('children', 'entry_ids')
    
    def __init__(self):
        self.children: Dict[str, 'TrieNode'] = {}
        self.entry_ids: Set[Any] = set()

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and compound phrases.
    """
    # Normalize dictionary keys: lowercase and split into components
    trie_root = TrieNode()
    exact_match_map: Dict[str, Set[Any]] = {}
    
    for phrase, entry_id in dictionary.items():
        # Normalize phrase and split into components (words and separators)
        normalized_phrase = phrase.lower()
        components = []
        current_component = []
        current_is_word = is_word_token(phrase[0]) if phrase else False
        
        for char in phrase:
            char_is_word = is_word_token(char)
            if char_is_word == current_is_word:
                current_component.append(char.lower())
            else:
                components.append(''.join(current_component))
                current_component = [char.lower()]
                current_is_word = char_is_word
        if current_component:
            components.append(''.join(current_component))
        
        # Add to exact match map if it's a single component
        if len(components) == 1:
            component = components[0]
            if component not in exact_match_map:
                exact_match_map[component] = set()
            exact_match_map[component].add(entry_id)
        
        # Add to trie for phrase lookup
        current_node = trie_root
        for component in components:
            if component not in current_node.children:
                current_node.children[component] = TrieNode()
            current_node = current_node.children[component]
        current_node.entry_ids.add(entry_id)
    
    return (exact_match_map, trie_root)

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[Tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.
    """
    exact_match_map, trie_root = dictionary_index
    tokens = list(tokens)
    annotations = [set() for _ in tokens]
    n = len(tokens)
    
    # First pass: exact matches
    for i, token in enumerate(tokens):
        normalized_token = token.lower()
        if normalized_token in exact_match_map:
            annotations[i].update(exact_match_map[normalized_token])
    
    # Second pass: phrase matches
    for i in range(n):
        current_node = trie_root
        j = i
        while j < n and current_node is not None:
            token = tokens[j]
            normalized_token = token.lower()
            
            # Check if current token matches any child of current node
            if normalized_token in current_node.children:
                current_node = current_node.children[normalized_token]
                if current_node.entry_ids:
                    # Found a phrase: annotate all tokens from i to j
                    for k in range(i, j + 1):
                        annotations[k].update(current_node.entry_ids)
                j += 1
            else:
                break
    
    # Handle leading/trailing separators (they shouldn't be part of any phrase)
    if n > 0:
        # Leading separators
        i = 0
        while i < n and not is_word_token(tokens[i]):
            annotations[i] = set()
            i += 1
        
        # Trailing separators
        i = n - 1
        while i >= 0 and not is_word_token(tokens[i]):
            annotations[i] = set()
            i -= 1
    
    return list(zip(tokens, annotations))
```
