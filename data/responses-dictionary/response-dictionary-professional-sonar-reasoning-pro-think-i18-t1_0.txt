1. **Dictionary Normalization**: Convert entries to lowercase and remove non-alphabetic characters.  
2. **Trie-based Prefix Matching**: For each token position, build possible phrases by ignoring separators and checking against normalized dictionary entries.  
3. **Annotation Propagation**: For valid phrases, annotate all tokens in their span, including separators between words.

```python
import collections

def build_dictionary_index(dictionary):
    """Builds a trie-like index for fast phrase matching."""
    index = {}
    max_length = 0
    entries = []
    
    for key in dictionary:
        normalized = ''.join([c.lower() for c in key if c.isalpha()])
        if normalized:
            if normalized not in index:
                index[normalized] = set()
            index[normalized].add(dictionary[key])
            if len(normalized) > max_length:
                max_length = len(normalized)
    return index, max_length

def annotate(tokens, dictionary_index):
    """Annotation function using precomputed index and max phrase length."""
    index, max_len = dictionary_index
    annotations = [set() for _ in tokens]
    n = len(tokens)
    
    for i in range(n):
        # Build normalized phrase candidates starting at i
        buffer = []
        for j in range(i, n):
            # Append lowercase letters, ignore others
            if tokens[j].isalpha():
                buffer.append(tokens[j].lower())
            # Check buffer at each step
            phrase = ''.join(buffer)
            if phrase in index:
                if j - i + 1 <= 2 * max_len:  # Prevent excessive look-behinds
                    for k in range(i, j + 1):
                        annotations[k].update(index[phrase])
            # Stop early if exceed max phrase length
            if len(buffer) > max_len:
                break
        # Check individual word matches
        word = ''.join([c.lower() for c in tokens[i] if c.isalpha()])
        if word in index:
            annotations[i].add(index[word])
    return [(token, set()) for token in tokens]
```

### Key Concepts

1. **Normalization**:  
   Convert dictionary entries to lowercase and remove non-alphabetic characters (e.g., `"AAA BBB"` → `"aaabbb"`). This allows phrases like `"AAA, BBB"` to match `"aaabbb"`.

2. **Annotation Propagation**:  
   For each token, build a **buffer** of lowercase alphabetic characters. At each step, check if the buffer matches a normalized dictionary entry. If matched, annotate **all tokens in the span** (including non-alphabetic separators) with the phrase's identifiers. Individual tokens are also checked against single-word entries.

3. **Efficiency**:  
   - **Trie-like prefix matching** minimizes redundant checks by leveraging buffer building.  
   - **Max-Length Pruning**: Stopping once the buffer exceeds the maximum dictionary entry length reduces unnecessary iterations.
