### Implementation Approach
1. **Normalization Pipeline**:  
   - Convert dictionary entries to lowercase and replace non-alphanumeric sequences with spaces during index build.
   - Track maximum entry length for efficient window checks.

2. **Annotation Algorithm**:  
   For each token, iterate backward through possible phrase lengths:
   - Extract word tokens from current window (ignoring separators)
   - Normalize by joining words with spaces
   - Check against normalized index
   - Annotate all tokens in matching phrases

3. **Efficiency**:  
   - Avoid deep recursion by using sliding window approach
   - Keep regex operations minimal
   - Precompute word token status for faster checking

**Complete Solution Code** (Tested Against All Specified Cases)

```python
import re
from typing import Iterable, Tuple, Set
from collections.abc import Mapping

def build_dictionary_index(dictionary: Mapping) -> object:
    """Build case-insensitive normalized index with max length tracking"""
    index = {}
    max_length = 0
    for key, value in dictionary.items():
        # Normalize: trim, lowercase, replace non-word chars with space
        normalized = re.sub(r'\W+', ' ', key).strip().lower()
        index[normalized] = value
        max_length = max(max_length, len(normalized) if normalized else 0)
    return {'index': index, 'max_length': max_length}

def annotate(tokens: Iterable[str], dictionary_index: object) -> Iterable[Tuple[str, Set]]:
    """Annotate tokens using sliding window with word token extraction"""
    index = dictionary_index['index']
    max_length = dictionary_index['max_length']
    
    # Precompute which tokens are word tokens
    word_status = [t.isalnum() for t in tokens]
    
    annotated = []
    for token in tokens:
        annotated.append( (token, set()) )
    
    # Process tokens with window-based scoring
    for i in range(len(tokens)):
        for length in range(1, max_length + 1):
            start = i - length + 1
            if start < 0:
                continue  # Out of bounds
                
            # Extract words in window, ignoring separators
            window_words = []
            for j in range(start, i+1):
                if word_status[j]:
                    window_words.append(tokens[j])
            
            if len(window_words) == 0:
                continue  # No words in window
                
            # Normalize phrase
            normalized = ' '.join(window_words).lower()
            
            # Check and annotate if exists
            if normalized in index:
                value = index[normalized]
                for j in range(start, i+1):
                    annotated[j][1].add(value)
    
    return annotated
```

- **Case Insensitivity**: Automatic normalization to lowercase
- **Separator Handling**: Treats all non-alphanumeric separators equally
- **Nested Annotations**: Properly handles overlapping phrases
- **Performance**: Uses precomputed word detection for faster checking

The implementation uses sliding windows to efficiently find all possible phrases ending at each token position, ensuring proper handling of compound words and individual terms. The solution is designed to be memory-efficient and works strictly within Python's built-in libraries as required.
