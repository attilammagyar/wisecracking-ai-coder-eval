## Algorithm Overview

**Core Ideas:**
1. **Dictionary Normalization:** Preprocess dictionary entries by replacing non-alphanumeric characters with spaces and converting to lowercase. This handles varying separators and ensures case-insensitivity.
2. **Stripping and Splitting:** Dictionary entries and tokens are normalized similarly, allowing direct string comparisons.
3. **Dynamic Phrase Checks:** For each token, check all possible phrase endings starting from the token and extending backward. This identifies overlapping phrases efficiently.
4. **Separator Handling:** Explicit checks exclude leading/trailing separators from annotations while including inner separators within valid phrases.

**Key Data Structures:**
- **Trie-Like Phrase Index:** A dictionary maps normalized phrase strings to entry IDs.
- **Precomputed Token Metadata:** Track whether each token is a separator (non-alphanumeric) for quick validation.

**Workflow:**
1. **Initialization:** Normalize dictionary entries and track the maximum phrase length.
2. **Annotation Process:** 
   - Precompute normalized tokens and separator status.
   - For each token, check individual entry validity.
   - Check backward window phrases, excluding invalid (separator-heavy) phrases.

```python
                if not is_separator[idx]:
                    valid = True
                    break
            if not valid:
                continue
            
            # Create normalized phrase string
            phrase = ' '.join(normalized_tokens[start:i+1])
            entry_id = phrases.get(phrase)
            if entry_id is not None:
                # Annotate all tokens in the phrase window
                for j in range(start, i+1):
                    annotations[j].add(entry_id)
    
    return [(token, annotations[i]) for i, token in enumerate(tokens)]
```
