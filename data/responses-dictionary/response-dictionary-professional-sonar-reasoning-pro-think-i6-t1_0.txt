To solve the text annotation problem efficiently while meeting all requirements, we use a two-phase approach: **dictionary normalization** to create an efficient lookup structure, and **span-based annotation** to handle compound phrases and separators.

---

## Approach Overview

1. **Dictionary Normalization**  
   Convert all dictionary entries to a standardized format:
   - **Lowercase** for case-insensitive matching.
   - **Replace non-alphanumeric characters** with spaces (e.g., `AAA, BBB` → `aaa bbb`).
   - **Collapse multiple spaces** to a single space.

2. **Span-Based Annotation**  
   For each token position, check all possible spans starting with an alphanumeric token and ending with an alphanumeric token:
   - **Normalize the span** to match dictionary wording.
   - **Check for dictionary matches** and annotate all tokens in the span.

3. **Efficiency Considerations**  
   - **Sliding window** to minimize redundant checks.
   - **Precomputed normalized tokens** to avoid repeated transformations.

## Solution Code

```python
import re
from collections.abc import Iterable, Mapping, Set

def build_dictionary_index(dictionary: Mapping) -> dict:
    index = {}
    for key in dictionary:
        normalized = key.lower()
        normalized = re.sub(r'\W+', ' ', normalized)
        normalized = normalized.strip()
        if normalized:
            normalized = ' '.join(normalized.split())
            index[normalized] = dictionary[key]
    return index

def annotate(tokens: Iterable[str], dictionary_index: dict) -> Iterable[tuple[str, Set]]:
    n = len(tokens)
    annotations = [set() for _ in range(n)]
    separators = [not t.isalnum() for t in tokens]
    
    # Step 1: Precompute normalized tokens without stripping
    normalized_tokens = []
    for t in tokens:
        normalized = re.sub(r'\W+', ' ', t.lower())
        normalized_tokens.append(normalized)
    
    # Step 2: Span-based matching
    for i in range(n):
        if separators[i]:
            continue  # Skip spans starting with a non-alphanumeric token
        for j in range(i, n):
            if separators[j]:
                break  # Stop at first non-alphanumeric end token
            # Form span and normalize
            span = ''.join(normalized_tokens[i:j+1])
            span = re.sub(r'\s+', ' ', span).strip()
            if span in dictionary_index:
                entry = dictionary_index[span]
                for k in range(i, j+1):
                    annotations[k].add(entry)
    
    return [(tokens[k], annotations[k]) for k in range(n)]
```

## Implementation Details

### Dictionary Normalization
1. **Case Insensitivity**  
   Convert all keys to lowercase to ensure `AAA` matches `aaa`.

2. **Separator Handling**  
   Replace commas, periods, and other non-alphanumeric characters with spaces, then collapse consecutive spaces.

3. **Efficient Lookup**  
   Use a dictionary mapping normalized strings to entries for O(1) lookups.

### Span-Based Annotation
1. **Sliding Window**  
   For each starting token `i`, check spans from `i` to `j` where both `i` and `j` are alphanumeric tokens.

2. **Normalization**  
   Form spans by joining normalized tokens, then replace multiple spaces with a single space.

3. **Annotation**  
   Add matching dictionary entries to all tokens in the span, including separators within the span.

This approach ensures correct handling of case, separators, and compound phrases while maintaining simplicity and efficiency.
