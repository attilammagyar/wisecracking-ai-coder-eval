## Algorithm Design: Explanation

### 1. **The Key Problem**

Given a stream of tokens (already split, possibly wordpieces and non-word), and a possibly more coarsely segmented dictionary (where entries can be whole words or phrases with spaces and even punctuation), we want to annotate every input token with the dictionary entries it helps instantiate. For individual dictionary words, match token-to-dict-entry. For phrases or compounds, all participating tokens (except leading/trailing separators) must be annotated.

We want efficient lookup for all *phrases*, i.e., possibly multi-token, possibly with interspersed separators. We also must handle separators/non-words in a forgiving way between tokens and between phrase dictionary keys.

### 2. **Dictionary Indexing**
We need:
- Case-insensitive matching.
- Efficient phrase lookup: given a start position in tokens, what is the longest/which phrases from the dictionary start at that point?
- Account for dictionary phrases that may have arbitrary separators between words (e.g., "AAA, BBB" should match ["AAA", " ", "*", "BBB"]).

**Approach:**  
We'll preprocess all dictionary entries into lowercased, *normalized token forms*, splitting them into sequences of word and separator "parts". We'll build a trie (a prefix tree), where each node represents one step of the normalized sequence of tokens and separators.

For lookup, we'll walk through tokens, and for each possible starting position, follow the trie, skipping over variable separators in the tokens, and matching words/separators as needed.

To make this efficient, we'll:
- Normalize both tokens and dictionary entries to lower-case.
- For dictionary phrases, split into "parts" where each part is either a word, or a separator. (Splitting on Unicode word boundaries.)
- Store entries in a trie structure for quick phrase/path matching.
- Keep track, for each dictionary phrase, of which tokens correspond to inner positions (not leading or trailing separators).
- For compound matching, allow flexible separators in the tokenized input, as long as they match the *order* of "parts" in the dictionary phrase.

### 3. **Token Classification (Word vs. Separator)**
We need to split both dictionary keys and input tokens into "word" and "separator". Python's `str.isalnum()` gives us a rough way to check if a string is a "word" (at least alphabetic/numeric) or a "separator" (punctuation, spaces, markdown, etc.).

### 4. **Annotation Algorithm**

- For every token position, try to match all possible phrases from that starting point using the trie.
- For every match, annotate all participating tokens (but only mark inner separators).
    - The leading and trailing separators of a phrase are never annotated, only the ones within the phrase.
- Also, annotate the token with the entry if the token matches a single-word dictionary entry.

Since phrases can overlap and be nested, we collect all such dictionary entries and aggregate into a set for each token.

### 5. **Efficiency**

By using a trie, we avoid repeated string operations for every sliding window match. Instead, we can consume tokens in a scan, and at each position, simultaneously walk the possible phrase matches down the trie, skipping over allowed separators.

### 6. **Implementation Plan**

- **Trie Construction:** For every phrase in the dictionary, split its pattern into normalized "part" list; insert it into the trie, noting the entry at the leaf.
- **Annotation:** For each token, run a scan down the trie to find all phrases matching any window starting at this token. Mark the relevant tokens with all entries matching phrases they participate in.
- Also, annotate tokens for singleton-word entries.
- Output a list of (token, set of matching entry-ids).

```python
import collections.abc
import re

def _is_word(token):
    """Heuristic to identify if a token is a word (matches \w)"""
    return any(c.isalnum() for c in token)

def _normalize_token(token):
    """Lowercase and strip meaningless surrounding whitespace for robust matching."""
    return token.lower()

def _split_phrase_to_parts(phrase):
    """
    Splits a phrase into alternating word/separator parts, preserving separators as explicit tokens.
    E.g. 'AAA, BBB' -> ['aaa', ',', 'bbb']
    """
    # Word: \w+; separator: \W+
    # We'll use re.findall
    parts = []
    for part in re.finditer(r'\w+|\W+', phrase):
        s = part.group(0)
        if _is_word(s):
            parts.append(s.lower())
        else:
            # normalize separators (collapse multiple whitespace, strip)
            # but preserve e.g. ',' as separator for distinctness
            s = s.strip()
            if s:
                parts.append(s)
            else:
                # treat blank space as a space (to match input tokens that are spaces)
                parts.append(' ')
    return parts

class _TrieNode:
    # Trie for fast multi-word phrase lookup
    __slots__ = ['children', 'entry_ids']
    def __init__(self):
        self.children = dict()           # part (str) -> _TrieNode
        self.entry_ids = set()           # Set[int]; end of phrase node(s)

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.
    """
    # There are two lookup types: by normalized single word, and as phrase
    word_entries = collections.defaultdict(set)  # str -> set of entry ids (for singleton tokens fast lookup)
    trie_root = _TrieNode()  # root of phrase trie

    for key, entry in dictionary.items():
        norm_key = key.lower()
        parts = _split_phrase_to_parts(norm_key)

        # Add all singleton words to word_entries
        if len(parts) == 1 and _is_word(parts[0]):
            word_entries[parts[0]].add(entry)

        # Insert into trie for phrase matching
        node = trie_root
        for part in parts:
            if part not in node.children:
                node.children[part] = _TrieNode()
            node = node.children[part]
        node.entry_ids.add(entry)

    # For annotation we need to remember:
    #   - trie_root
    #   - word_entries
    return {
        'trie_root': trie_root,
        'word_entries': word_entries
    }

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.

    Return:
        annotated_tokens:   A list containing (token, annotations) pairs for each token in tokens.
    """
    # Prepare
    trie = dictionary_index['trie_root']
    word_entries = dictionary_index['word_entries']
    # To enable efficient in-place annotation, process into a list
    tokens = list(tokens)
    N = len(tokens)
    # Each position is a set, to which we will add all relevant entries
    annotations = [set() for _ in range(N)]

    # --- Step 1: phrase match annotation (trie-based, n-gram scan) ---
    # For each position, try all phrases starting there
    # For each match, annotate all phrase tokens (word+inner-separators, skip leading/trailing separators)

    # Precompute for each token: is it a word or a separator
    is_word = [_is_word(tok) for tok in tokens]
    norm_tokens = [_normalize_token(tok) for tok in tokens]

    for i in range(N):
        # For phrases starting at position i
        trie_nodes = [(trie, i, [])]  # (current trie node, current token position, part_positions: (token indexes))
        while trie_nodes:
            node, pos, part_positions = trie_nodes.pop()
            if node.entry_ids:
                # Found a phrase match spanning part_positions
                # Figure out semantic (exclude leading/trailing separator tokens)
                if part_positions:
                    # Identify spans: tokens that are inner or word positions
                    # To exclude leading/trailing separators: drop if part_positions[0/last] is separator
                    first, last = part_positions[0], part_positions[-1]
                    # Compose new set of indexes to annotate:
                    for idx, token_idx in enumerate(part_positions):
                        if len(part_positions) == 1:
                            # Single token: always annotate
                            annotate_this = True
                        elif idx == 0 or idx == len(part_positions) - 1:
                            # If first or last: annotate only if it's a word
                            annotate_this = is_word[token_idx]
                        else:
                            # Inner: always annotate (word or separator)
                            annotate_this = True
                        if annotate_this:
                            annotations[token_idx].update(node.entry_ids)
            # Continue scan, if within token bounds
            if pos < N:
                # Try to extend match by the next token
                next_token = norm_tokens[pos]
                # Try all options: if current trie node can continue via:
                #   a word token (if next_token is a word)
                #   a separator (if next_token is separator)
                # (Try to match both, if both possible)
                nexts = []
                if is_word[pos]:
                    # Try word edge (if present)
                    if next_token in node.children:
                        nexts.append( (node.children[next_token], pos+1, part_positions+[pos]) )
                else:
                    # Try separator edge (if present)
                    # Note: we can have spaces, comma, etc.
                    sep_key = next_token
                    if sep_key in node.children:
                        nexts.append( (node.children[sep_key], pos+1, part_positions+[pos]) )
                trie_nodes.extend(nexts)
    # --- Step 2: individual token annotation (for singleton-word dict entries) ---
    for idx, (norm_tok, w) in enumerate(zip(norm_tokens, is_word)):
        if w:
            entries = word_entries.get(norm_tok)
            if entries:
                annotations[idx].update(entries)
    # --- Step 3: output ---
    annotated_tokens = [(tok, frozenset(annotations[idx])) for idx, tok in enumerate(tokens)]
    return annotated_tokens
```
