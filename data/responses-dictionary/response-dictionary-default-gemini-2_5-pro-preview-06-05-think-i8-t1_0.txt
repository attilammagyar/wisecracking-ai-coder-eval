### Solution Explanation

The problem requires an algorithm to annotate a sequence of text tokens with relevant dictionary entries. The matching process must handle single words, multi-word phrases, and compound words, all while being insensitive to capitalization and the specific separators used. Overlapping and nested matches need to be identified correctly.

To solve this efficiently, I've designed a two-part solution: an indexing step (`build_dictionary_index`) and an annotation step (`annotate`).

#### 1. The Dictionary Index Data Structure

A simple dictionary lookup is insufficient due to the complexity of matching phrases and compound words. A Trie (prefix tree) is an ideal data structure for this kind of prefix-based search. To handle the different types of matches, I use two separate Tries within the index:

*   **Phrase Trie**: This Trie stores multi-word phrases. Each path from the root represents a sequence of normalized (lowercased) word tokens. For example, the dictionary entry `"black swan"` would be stored as a path `root -> "black" -> "swan"`. This structure makes it easy to match a sequence of word tokens from the input text, regardless of the separators between them.
*   **Word Trie**: This Trie stores single words on a character-by-character basis. For example, `"event"` is stored as `root -> 'e' -> 'v' -> 'e' -> 'n' -> 't'`. This is crucial for matching compound words, where multiple input tokens might concatenate to form a single dictionary entry (e.g., tokens `["AAA"]` and `["BBB"]` forming the dictionary word `"AAABBB"`).

The `build_dictionary_index` function is responsible for parsing the input dictionary, normalizing the keys, and populating these two Tries. The resulting index, containing the roots of both Tries, is then passed to the `annotate` function.

#### 2. The Annotation Algorithm

The `annotate` function takes the tokenized text and the dictionary index to produce the final annotations. Its logic is as follows:

1.  **Word Identification**: It first performs a pre-processing pass on the input tokens to identify which tokens are "words" (i.e., contain alphanumeric characters) and which are separators. It stores the words and their original indices for quick access.

2.  **Iterative Matching**: The algorithm then iterates through each word in the text, treating it as a potential start of a match. From each starting word, it performs two parallel searches forward through the token stream:
    *   **Phrase Search**: It consumes subsequent word tokens from the input to traverse the **Phrase Trie**. If a path corresponds to a valid dictionary phrase, all tokens that constitute that phrase (including the separators between the words) are annotated.
    *   **Compound Word Search**: It consumes subsequent *contiguous* word tokens, concatenates them, and uses the resulting string to traverse the **Word Trie**. If a path corresponds to a valid dictionary word, all tokens that form the compound word are annotated.

3.  **Aggregation**: This process is repeated for every possible starting word, ensuring that all possible matches (including overlapping and nested ones) are found. The annotations for each token are collected in a set to automatically handle duplicates.

This approach is both robust and efficient. By pre-building an optimized index, it avoids slow, repetitive string operations during the annotation phase, and the Trie-based search efficiently handles multiple concurrent match attempts.

import collections.abc
import re

class _TrieNode:
    """
    A node in a Trie data structure. It is used for both the phrase trie and
    the word trie. It's a private implementation detail of the indexing mechanism.
    """
    def __init__(self):
        # Maps a token (for phrase trie) or a character (for word trie)
        # to the next node.
        self.children = {}
        # Stores the set of dictionary values for entries ending at this node.
        self.values = set()

def _is_word(token: str) -> bool:
    """
    Determines if a token is a "word" component. A token is considered a word
    if it contains at least one alphanumeric character. This correctly
    identifies words while excluding pure punctuation or separator tokens like
    " ", "*", or ".".
    """
    return re.search(r'[a-zA-Z0-9]', token) is not None

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    The index consists of two Tries, returned as a tuple:
    1. A "phrase Trie" for multi-word phrases, built on token sequences.
    2. A "word Trie" for single words, built on character sequences.

    Parameters:
        dictionary: Mapping strings (keys) to meanings (values).
    """
    phrase_trie_root = _TrieNode()
    word_trie_root = _TrieNode()

    for key, value in dictionary.items():
        # Normalize the key by lowercasing and extracting word components.
        # This makes matching insensitive to case and the types of separators used.
        key_tokens = re.findall(r'[a-z0-9]+', key.lower())

        if not key_tokens:
            continue

        if len(key_tokens) > 1:
            # It's a multi-word phrase; add it to the phrase trie.
            node = phrase_trie_root
            for token in key_tokens:
                node = node.children.setdefault(token, _TrieNode())
            node.values.add(value)
        else:
            # It's a single word; add it to the word trie character by character.
            word = key_tokens[0]
            node = word_trie_root
            for char in word:
                node = node.children.setdefault(char, _TrieNode())
            node.values.add(value)

    return (phrase_trie_root, word_trie_root)

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.

    Parameters:
        dictionary_index:   A dictionary index created by build_dictionary_index().
        tokens:             The tokens to be annotated.

    Return:
        annotated_tokens:   A list containing (token, annotations) pairs for
                            each token in tokens.
    """
    phrase_trie_root, word_trie_root = dictionary_index
    tokens = list(tokens)
    annotated_tokens = [(token, set()) for token in tokens]
    
    if not tokens:
        return []

    # Pre-process to identify all word tokens and their original indices.
    words = [
        (i, token.lower()) for i, token in enumerate(tokens) if _is_word(token)
    ]

    # Iterate through each word, treating it as a potential start of a match.
    for i in range(len(words)):
        start_token_idx, _ = words[i]

        # --- 1. Phrase Matching ---
        # Search for phrases starting with the word at words[i].
        node = phrase_trie_root
        for j in range(i, len(words)):
            current_token_idx, current_word = words[j]
            
            if current_word not in node.children:
                break
            
            node = node.children[current_word]
            if node.values:
                # Found a phrase. Annotate all tokens in the span from the
                # first word to the last word of the phrase.
                for k in range(start_token_idx, current_token_idx + 1):
                    annotated_tokens[k][1].update(node.values)

        # --- 2. Compound Word Matching ---
        # Search for compound words formed by concatenating contiguous tokens.
        node = word_trie_root
        last_token_idx = start_token_idx - 1
        for j in range(i, len(words)):
            current_token_idx, current_word = words[j]

            # A compound word must be formed by contiguous tokens.
            if j > i and current_token_idx != last_token_idx + 1:
                break
            last_token_idx = current_token_idx
            
            # Traverse the word trie character by character for the current word.
            can_continue_match = True
            for char in current_word:
                if char not in node.children:
                    can_continue_match = False
                    break
                node = node.children[char]
            
            if not can_continue_match:
                break
            
            if node.values:
                # Found a compound word. Annotate all tokens in its span.
                for k in range(start_token_idx, current_token_idx + 1):
                    annotated_tokens[k][1].update(node.values)

    return annotated_tokens
