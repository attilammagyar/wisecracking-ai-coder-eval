To implement an efficient text annotation algorithm for language learners, we'll use the following approach:

### Main Ideas

**1. Normalized Dictionary Index**
- **Normalization**: Convert all dictionary entries to lowercase and replace non-alphanumeric characters with spaces. This handles case insensitivity and varying word separators like commas or asterisks.
- **Phrase Preprocessing**: Break normalized phrases into word sequences for exact matching while allowing any non-alphanumeric separators between words.

**2. Annotation Algorithm**
- **Individual Token Search**: Check if each token (case-insensitive) exists as a standalone dictionary entry.
- **Phrase Matching**: For each phrase in descending order of length, find matches in the token sequence ignoring non-alphanumeric separators between words. Annotate all tokens in the matched sequence.

**Efficiency**: Sorting phrases by descending length ensures longer phrases are processed first, avoiding premature short matches. Using sets for annotations ensures unique entries.

### Implementation

```python
import re
from collections.abc import Iterable, Mapping

def build_dictionary_index(dictionary: Mapping) -> object:
    """Build optimized index for fast lookups"""
    normalized = {}
    phrases = []
    
    for key, value in dictionary.items():
        # Normalize key: replace non-alphanumeric with space, lowercase
        norm_key = re.sub(r'[^a-zA-Z0-9]', ' ', key).lower()
        norm_key = ' '.join(norm_key.split())
        
        if norm_key:
            normalized[norm_key] = value
            phrases.append((norm_key.split(), value))
    
    # Sort phrases by descending length to prioritize longer matches
    phrases.sort(key=lambda x: -len(x[0]))
    return (normalized, phrases)

def annotate(tokens: Iterable[str], dictionary_index: object) -> Iterable[tuple[str, Iterable]]:
    """Annotate tokens with dictionary entries"""
    normalized_dict, phrases = dictionary_index
    annotated = [set() for _ in tokens]
    
    # Check individual tokens
    for i, token in enumerate(tokens):
        token_lower = token.lower()
        if token_lower in normalized_dict:
            annotated[i].add(normalized_dict[token_lower])
    
    # Check phrases
    for phrase_words, phrase_id in phrases:
        for start in range(len(tokens) - len(phrase_words) + 1):
            current = start
            match = True
            
            for word in phrase_words:
                if current >= len(tokens): break
                if tokens[current].lower() != word: 
                    match = False
                    break
                current += 1
                
                # Skip non-alphanumeric separators
                while current < len(tokens):
                    if all(not c.isalnum() for c in tokens[current]):
                        current += 1
                    else:
                        break
            
            if match:
                end = current - 1
                for pos in range(start, end + 1):
                    if pos < len(tokens):
                        annotated[pos].add(phrase_id)
    
    return [(tokens[i], s) for i, s in enumerate(annotated)]
```

| **Length Sorting** | Sort phrases by descending length | Ensures longest matches are found first, avoiding partial overlaps |
| **Annotation Storage** | Sets for token entries | Prevents duplicate entries, efficient membership checks |

This solution efficiently handles compound phrases, varying separators, and overlapping matches using built-in Python structures without external dependencies.
