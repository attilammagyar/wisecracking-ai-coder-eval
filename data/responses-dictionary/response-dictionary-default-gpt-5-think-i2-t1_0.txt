Main ideas

- Normalize and index dictionary:
  - We lowercase keys and split each key into “terms” made of alphanumeric characters. Non-alphanumeric characters are treated as separators.
  - If a key has exactly one term (e.g., "aaabbb"), it is a single-term entry and is stored in a hash map for O(1) lookup.
  - If a key has 2+ terms (e.g., "aaa bbb" or "aaa, bbb"), it is a phrase entry. We store all such phrases in a trie keyed by the sequence of terms. This allows fast scanning of the token stream for multi-term phrases. The separators in the dictionary are ignored during indexing; only the sequence of terms matters.

- Token classification and normalization:
  - A token is a “word” if all its characters are alphanumeric (token.isalnum()). Otherwise it’s a separator.
  - Lookup is case-insensitive: we normalize word tokens to lowercase.

- Matching rules enforced by scanning:
  - Single-word entries:
    - A word token matches a single-term entry directly.
    - Compound words that got split by the tokenizer (e.g., ["AAA","BBB"] vs "AAABBB") are matched by concatenating contiguous word tokens that have no separator between them. The match must start and end at token boundaries; we never cut inside a token (so no mid-token matches).
  - Multi-term phrase entries:
    - We scan over the sequence of word tokens using the trie. Between consecutive terms in a phrase there must be at least one separator token in the text (i.e., the corresponding word tokens are not adjacent).
    - A matched phrase annotates all tokens from the first word to the last word inclusive, which includes only the inner separators (no leading/trailing separators outside the phrase span).

- Overlaps and nesting:
  - We start phrase scanning at every word position and collect all phrase ends we encounter in the trie. This naturally supports overlapping and nested phrases.

- Complexity:
  - Single-term lookups are O(1) per word token. Compound word matching within contiguous runs of word tokens is quadratic in the run length, which is typically small in real tokenizations. Phrase scanning is O(W * L) where W is the number of word tokens and L the maximum phrase length in the dictionary.

import collections.abc

class _PhraseTrieNode:
    __slots__ = ("children", "ends")
    def __init__(self):
        self.children = {}  # term(str) -> _PhraseTrieNode
        self.ends = set()   # set of dictionary values ending at this node

def _extract_terms(text: str) -> list[str]:
    """
    Split a dictionary key into alphanumeric terms (case-insensitive).
    Non-alphanumeric characters are treated as separators.
    """
    terms = []
    buf = []
    for ch in text:
        if ch.isalnum():
            buf.append(ch.lower())
        else:
            if buf:
                terms.append("".join(buf))
                buf = []
    if buf:
        terms.append("".join(buf))
    return terms

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build an index consisting of:
      - single: dict term(str) -> set(values)
      - phrase_trie: root _PhraseTrieNode for phrases with 2+ terms
    """
    single = {}  # term -> set(values)
    root = _PhraseTrieNode()  # phrase trie root

    for key, value in dictionary.items():
        terms = _extract_terms(key)
        if not terms:
            continue
        if len(terms) == 1:
            term = terms[0]
            s = single.get(term)
            if s is None:
                s = set()
                single[term] = s
            s.add(value)
        else:
            # Insert sequence of terms into trie
            node = root
            for term in terms:
                child = node.children.get(term)
                if child is None:
                    child = _PhraseTrieNode()
                    node.children[term] = child
                node = child
            node.ends.add(value)

    return {"single": single, "phrase_trie": root}

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    tokens = list(tokens)
    n = len(tokens)
    single = dictionary_index["single"]
    trie_root: _PhraseTrieNode = dictionary_index["phrase_trie"]

    # Classify tokens and normalize words
    is_word = [False] * n
    norm_word = [None] * n
    for i, tok in enumerate(tokens):
        if tok.isalnum():
            is_word[i] = True
            norm_word[i] = tok.lower()

    annotations = [set() for _ in range(n)]

    # 1) Single-term annotations:
    #    - direct per-token lookup
    #    - compound word formed by concatenating contiguous word tokens (no separators)
    i = 0
    while i < n:
        if not is_word[i]:
            i += 1
            continue

        # Find run [i..j] of contiguous word tokens (no separators between them)
        j = i
        while j + 1 < n and is_word[j + 1]:
            j += 1

        # For each start k in the run, grow concatenation across tokens k..t
        # and annotate if concatenation is an entry.
        for k in range(i, j + 1):
            concat = ""
            for t in range(k, j + 1):
                concat += norm_word[t]
                vals = single.get(concat)
                if vals:
                    for pos in range(k, t + 1):
                        annotations[pos].update(vals)

        i = j + 1

    # 2) Phrase annotations (2+ terms), separators-insensitive, but
    #    require at least one separator between consecutive terms in text.
    # Build list of positions of word tokens
    word_positions = [idx for idx in range(n) if is_word[idx]]

    W = len(word_positions)
    # Quick skip if no phrases
    has_phrases = bool(trie_root.children)
    if has_phrases and W:
        for wi in range(W):
            start_pos = word_positions[wi]
            first_term = norm_word[start_pos]
            node = trie_root.children.get(first_term)
            if node is None:
                continue

            # Try to extend with subsequent word tokens.
            # We require at least one separator token between consecutive terms,
            # i.e., the next word token must not be adjacent (index difference > 1).
            for wj in range(wi + 1, W):
                prev_tok_idx = word_positions[wj - 1]
                cur_tok_idx = word_positions[wj]

                # If no separator between prev and current word token, phrase can't continue.
                if cur_tok_idx == prev_tok_idx + 1:
                    break

                term = norm_word[cur_tok_idx]
                child = node.children.get(term)
                if child is None:
                    break
                node = child

                if node.ends:
                    # Annotate from first word token to current word token inclusive
                    for t in range(start_pos, cur_tok_idx + 1):
                        annotations[t].update(node.ends)

    # Build result
    annotated_tokens = [(tok, annotations[i]) for i, tok in enumerate(tokens)]
    return annotated_tokens
