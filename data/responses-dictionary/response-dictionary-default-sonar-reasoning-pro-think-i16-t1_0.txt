### Approach
1. **Dictionary Indexing**  
   Convert dictionary entries into normalized forms (lowercase, non-alphanumeric characters removed) for case-insensitive matching. This creates a map from concatenated word strings to entries.

2. **Token Processing**  
   - **Normalization**: Convert each token to lowercase and filter out non-alphabetic characters for dictionary matching.
   - **Individual Words**: Directly match single-token entries.
   - **Compound Phrases**: Check sequences of word tokens for matches against normalized dictionary entries. Include all intermediate separators while excluding leading/trailing separators.

3. **Annotation**  
   Track annotations using a set per token. Add matches for individual words and all tokens in matched compound phrases.

import collections.abc

def build_dictionary_index(dictionary: collections.abc.Mapping) -> dict:
    """Create normalized index of dictionary entries"""
    index = {}
    for key, value in dictionary.items():
        # Normalize: lowercase + remove non-A-Za-z characters
        normalized = ''.join(re.findall(r'[A-Za-z]+', key)).lower()
        index[normalized] = value
    return index
