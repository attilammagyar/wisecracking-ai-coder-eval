## Algorithm Overview
1. **Dictionary Normalization**: 
   - Convert all entries to lowercase
   - Remove non-alphanumeric characters
   - Store matches in a hash table for O(1) lookups

2. **Annotate Process**:
   - **Single Token Matches**: Check each token individually against normalized dictionary
   - **Compound Phrase Matches**: For each starting token, dynamically expand to check all possible phrases by:
     - Including intermediate separators (non-word tokens)
     - Ensuring phrases start/end with word tokens
     - Normalizing concatenated forms for dictionary matching

## Solution Implementation
```python
from collections import defaultdict

def build_dictionary_index(dictionary: dict) -> dict:
    import re
    pattern = re.compile('[^a-z0-9]')  # Precompile regex once
    normalized_dict = defaultdict(set)
    
    for entry, entry_id in dictionary.items():
        normalized = pattern.sub('', entry.lower())
        normalized_dict[normalized].add(entry_id)
    
    return dict(normalized_dict)

def annotate(tokens: list[str], dictionary_index: dict) -> list[tuple[str, set]]:
    import re
    pattern = re.compile('[^a-z0-9]')
    num_tokens = len(tokens)
    annotations = [set() for _ in range(num_tokens)]
    
    # Single token matches
    for i, token in enumerate(tokens):
        normalized = pattern.sub('', token.lower())
        if normalized in dictionary_index:
            annotations[i].update(dictionary_index[normalized])
    
    # Compound phrase matches
    for i in range(num_tokens):
        norm_i = pattern.sub('', tokens[i].lower())
        if not norm_i:
            continue
        
        for j in range(i, num_tokens):
            norm_j = pattern.sub('', tokens[j].lower())
            if not norm_j:
                continue
            
            # Build normalized phrase from i to j
            normalized_phrase = ''.join(
                pattern.sub('', tokens[k].lower()) 
                for k in range(i, j+1)
            )
            
            if normalized_phrase in dictionary_index:
                for k in range(i, j+1):
                    annotations[k].update(dictionary_index[normalized_phrase])
    
    return [(tokens[i], annotations[i]) for i in range(num_tokens)]
```

## Key Innovations
1. **Efficient Normalization**:
   - Regex preprocessing removes special characters while preserving word detection
   - Lowercase conversion ensures case-insensitive matching

2. **Dynamic Phrase Expansion**:
   - Nested loops for starting/ending indices
   - Greedy expansion of phrase length
   - Automatic handling of multiple phrase overlaps

3. **Optimized Lookup**:
   - Preprocessed dictionary for O(1) matches
   - Batched updates for overlapping phrases
   - Early termination for invalid character sequences
