### Solution Explanation

#### Main Ideas
1. **Dictionary Index Construction**:
   - We'll normalize dictionary keys to lowercase for case-insensitive lookup.
   - We'll build a trie (prefix tree) for efficient phrase lookup. Each node will store:
     - A dictionary of child nodes (characters to nodes)
     - A set of dictionary entry IDs for complete words ending at that node
   - We'll also maintain a separate set of individual words for quick single-word lookups.

2. **Annotation Algorithm**:
   - For each token, we'll:
     - Check if it's a word (contains at least one letter) or separator
     - For words: look up individual word matches
     - Then look for compound phrases starting at that position by walking the trie:
       - Keep track of current node in trie
       - When we reach a node with entries, add those to all tokens in the current phrase
       - Skip non-word tokens during phrase matching (but include them in the phrase span)
     - Only include inner separators in phrase annotations (not leading/trailing ones)

#### Data Structures
- **Trie**: For efficient phrase prefix matching
- **Word Set**: For quick individual word lookups
- **Normalization**: All dictionary keys are normalized to lowercase for case-insensitive matching

#### Algorithm Complexity
- **Index Construction**: O(N*L) where N is number of dictionary entries and L is average length
- **Annotation**: O(M*K) where M is number of tokens and K is max phrase length in dictionary

```python
import collections.abc
from typing import Dict, Set, List, Tuple, Any

class TrieNode:
    __slots__ = ('children', 'entries')
    
    def __init__(self):
        self.children: Dict[str, 'TrieNode'] = {}
        self.entries: Set[Any] = set()

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.
    """
    trie = TrieNode()
    word_entries = {}
    
    for key, entry in dictionary.items():
        # Normalize key to lowercase and split into words
        normalized_key = key.lower()
        word_entries[normalized_key] = entry
        
        # Insert into trie
        node = trie
        for char in normalized_key:
            if char not in node.children:
                node.children[char] = TrieNode()
            node = node.children[char]
        node.entries.add(entry)
    
    return {
        'trie': trie,
        'word_entries': word_entries,
    }

def _is_word_token(token: str) -> bool:
    """Check if token contains at least one letter (not a pure separator)."""
    return any(c.isalpha() for c in token)

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.
    """
    tokens = list(tokens)  # Need random access for phrase matching
    annotated_tokens: List[Tuple[str, Set]] = []
    annotations = [set() for _ in tokens]  # Temporary storage for phrase matches
    
    word_entries = dictionary_index['word_entries']
    trie = dictionary_index['trie']
    
    for i, token in enumerate(tokens):
        # Individual word lookup (case-insensitive)
        if _is_word_token(token):
            lower_token = token.lower()
            if lower_token in word_entries:
                annotations[i].add(word_entries[lower_token])
        
        # Look for phrases starting at this position
        current_node = trie
        j = i
        phrase_start = i
        phrase_end = i
        
        while j < len(tokens):
            token_j = tokens[j]
            
            if _is_word_token(token_j):
                # Try to match each character in the word
                matched = False
                for char in token_j.lower():
                    if char in current_node.children:
                        current_node = current_node.children[char]
                        matched = True
                    else:
                        break
                
                if not matched:
                    break
                
                phrase_end = j
                
                # Add entries if we have a complete match
                if current_node.entries:
                    for k in range(phrase_start, phrase_end + 1):
                        if k == phrase_start or k == phrase_end or _is_word_token(tokens[k]):
                            annotations[k].update(current_node.entries)
                        elif k > phrase_start and k < phrase_end:
                            # Inner separator - include in phrase
                            annotations[k].update(current_node.entries)
            else:
                # Separator - skip but include in phrase span
                phrase_end = j
                j += 1
                continue
            
            j += 1
    
    # Combine tokens with their annotations
    for token, annotation in zip(tokens, annotations):
        annotated_tokens.append((token, annotation))
    
    return annotated_tokens
```

4. **Separator Handling**: Inner separators are included in phrase annotations, while leading/trailing ones are excluded.
