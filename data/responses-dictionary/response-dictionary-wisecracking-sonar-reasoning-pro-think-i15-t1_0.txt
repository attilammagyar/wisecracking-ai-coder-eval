So, you wanna build a text annotation system for language learners. Let's cut through the noise. The core challenge is matching both individual words and compound phrases efficiently, especially when separators vary. Here's the distilled approach:

**Main Concepts**
1. **Case Insensitivity & Normalization**: Convert all dictionary entries to lowercase during preprocessing.
2. **Two-Layer Matching**:
   - **Phrase Matching**: Handle multi-word phrases with any separators using word sequences
   - **Exact Matching**: Catch concatenated compound words (e.g., tokens "AAA" and "BBB" forming "AAABBB")

**Algorithm Breakdown**
1. **Dictionary Indexing** (build_dictionary_index)
   - Convert each dictionary entry into two forms:
     - **Phrase Sequence**: Split entries into word lists (ignoring separators), store as tuples for quick lookup
     - **Exact String**: Store entire entries as lowercase for direct matches

2. **Annotation Logic**
   - **Phrase Detection**: Check all word sequences in the token list against the phrase index. For matches, annotate all tokens between the first and last word in the sequence (including separators).
   - **Exact Matches**: Check each token individually and all contiguous token sequences against the exact string index.

**Code Implementation**
```python
import re
from collections.abc import Mapping, Iterable
from typing import Tuple, Set, Iterable, Optional

def build_dictionary_index(dictionary: Mapping[str, object]) -> dict:
    phrase_index = {}
    word_index = {}
    
    for key, entry in dictionary.items():
        # Process phrase sequences (split by non-word characters)
        words = [word.lower() for word in re.split(r'\W+', key) if word]
        if words:
            phrase_seq = tuple(words)
            phrase_index.setdefault(phrase_seq, set()).add(entry)
        
        # Process exact string matches
        word_lower = key.lower()
        word_index[word_lower] = entry  # Later entries overwrite duplicates
    
    return {'phrase_index': phrase_index, 'word_index': word_index}

def annotate(tokens: Iterable[str], dictionary_index: dict) -> Iterable[Tuple[str, Set]]:
    phrases = dictionary_index['phrase_index']
    words = dictionary_index['word_index']
    n = len(tokens)
    annotations = [set() for _ in range(n)]
    
    # Extract words and their positions for phrase matching
    word_sequence = []
    word_positions = []
    for i, token in enumerate(tokens):
        if not re.match(r'^\W+$', token):  # Assume non-word tokens have only non-word chars
            word_sequence.append(token.lower())
            word_positions.append(i)
    
    # Check phrase sequences (words separated by any separators)
    m = len(word_sequence)
    for i in range(m):
        for j in range(i, m):
            phrase = tuple(word_sequence[i:j+1])
            if phrase in phrases:
                # Mark tokens from first to last word's position
                start = word_positions[i]
                end = word_positions[j]
                for k in range(start, end + 1):
                    annotations[k].update(phrases[phrase])
    
    # Check individual word matches
    for i, token in enumerate(tokens):
        if token.lower() in words:
            annotations[i].add(words[token.lower()])
    
    # Check compound word matches (contiguous token sequences)
    for i in range(n):
        concat = []
        for j in range(i, n):
            concat.append(tokens[j])
            lower_concat = ''.join(concat).lower()
            if lower_concat in words:
                for k in range(i, j + 1):
                    annotations[k].add(words[lower_concat])
    
    return [(token, annotations[i]) for i, token in enumerate(tokens)]
```

**Why This Works**
- **Efficient Preprocessing**: Dictionary is indexed once with O(n) complexity
- **Dual Matching**: Handles both space-separated phrases ("AAA BBB") and concatenated compounds ("AAABBB")
- **Overlap Handling**: Each token accumulates annotations from all relevant matches
- **Case Insensitivity**: All checks use lowercase normalized strings

**Performance Notes**
While the nested loops imply O(n²) complexity, this is acceptable for typical language learning scenarios with relatively short text passages. Real-world optimizing might involve signalling with dynamic programming or using Aho-Corasick for patterns, but the problem constraints prioritize simplicity and correct test case passing.
