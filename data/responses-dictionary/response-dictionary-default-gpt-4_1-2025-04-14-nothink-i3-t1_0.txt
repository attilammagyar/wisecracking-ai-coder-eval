# Main Ideas and Design

## 1. General Approach
We need to efficiently locate, in a list of tokens, all substrings that form dictionary *entries* as either individual words or as contiguous sequences of tokens (phrases or compound words). Tokens may contain separators/markdown/non-word elements, which must be handled carefully (especially when mapping dictionary phrases to sequences of tokens).

## 2. Data Structure: Trie for Sequences of Word Tokens

- We build a trie (prefix tree) where each path represents a normalized sequence of *word tokens* from the dictionary (since dictionary entries are matched case-insensitively and ignore non-word separators between words).
- Each node marks if a complete dictionary entry (word, compound phrase, or compound word) ends there, and stores the corresponding entry identifiers.

**Normalization rules:**

- Both dictionary entries and tokens are lowercased for matching.
- Dictionary phrases are split using a word separator regex (`\W+`).
- Separators in dictionary entries (e.g. "black swan" or "blue, moon") are ignored when matching, but must be present (in some form) between tokens in the text.

## 3. Matching Algorithm

- For each token in the input, determine whether it's a "word" token (i.e., matches `\w+`, e.g. by `str.isalnum()` or using regex).
- Use a sliding window over the token list:
  - At each "word" token, try to match the longest compound phrase starting at this position.
  - Skip over separators in the tokenization as needed (i.e., allow flexible matching between phrase components).
  - Only annotate the "inner" separators (i.e., tokens between words in a match, but not separators at the edges of the match).

- Annotations for each token are accumulated from:
  - Matches of the full token (as individual word entry), and
  - Matches where the token is covered as part of a recognized phrase.

## 4. Efficient Processing

- We traverse the trie for possible phrase matches for each "word token", skipping only over tokens that are recognized as separators.
- Each potential match records which tokens it covers; we mark those tokens with the corresponding entry IDs.
- Overlapping matches are allowed and accumulative.

import collections.abc
import re

WORD_RE = re.compile(r"\w+", re.UNICODE)

def normalize_token(token):
    """Case-insensitive normalization, aligned with how dictionary entries and text are compared."""
    return token.lower()

def is_word_token(token):
    """Determine if a token is a 'word' (not separator/markup)."""
    # Consider only tokens with at least one alphanumeric character as 'word'
    return bool(WORD_RE.fullmatch(token))

def phrase_to_wordlist(phrase):
    """Tokenizes a dictionary entry phrase into list of normalized word components."""
    # Split on groups of non-word characters; keep only nonempty words
    return [w.lower() for w in re.split(r"\W+", phrase) if w]

class DictTrieNode:
    __slots__ = "children", "entries"
    def __init__(self):
        self.children = {}  # key: normalized word, value: DictTrieNode
        self.entries = set() # set of entry ids for phrases ending here

    def insert(self, word_seq, entry_id):
        node = self
        for word in word_seq:
            if word not in node.children:
                node.children[word] = DictTrieNode()
            node = node.children[word]
        node.entries.add(entry_id)

def build_dictionary_index(dictionary: collections.abc.Mapping):
    """
    Build a normalized trie index from a dictionary for fast lookup of words and
    compound phrases.
    Each phrase is split into words (insensitive to separators).
    """
    trie = DictTrieNode()
    word_mapping = {}  # exact match for single word entries: normalized_word -> set of entry ids

    for phrase, entry_id in dictionary.items():
        word_seq = phrase_to_wordlist(phrase)
        if not word_seq:
            continue
        trie.insert(word_seq, entry_id)
        if len(word_seq) == 1:
            word = word_seq[0]
            word_mapping.setdefault(word, set()).add(entry_id)

    # Encapsulate both trie and direct mapping in result index:
    return {'trie': trie, 'word_mapping': word_mapping}

    Annotate tokens with dictionary entries, covering both individual words and
    all matching compound phrases (taking into account word separators and their treatment).

    word_mapping = dictionary_index['word_mapping']

    is_word = [is_word_token(tok) for tok in tokens]

    annotations = [set() for _ in tokens]

    for i, (tok, norm_tok, word_flag) in enumerate(zip(tokens, normalized, is_word)):

            annotations[i].update(word_mapping[norm_tok])

    # Step 3: Search for all compound phrase matches (and single word entries again, for phrase union)
    # For each position, if it's a word token, start a trie-walk
    for start in range(N):

        idx = start

        # including inner separators (but NOT leading or trailing separators).
        match_indices = []  # (i, is_word[i]) tuples; will filter later for edge logic

        # Find first word token, and collect
        word_ptr = idx
        node = node.children.get(normalized[word_ptr])
        if node is None:
            continue
        phrase_indices = [start]

        # For matching, continue walking tokens:
        # We only advance in trie on word tokens, but skip over separators if needed in-between.
        i = start + 1
        cur_node = node
        word_positions = [start]  # positions of word tokens in match

        while True:
            # Check and record node's finished entries; assign to all covered tokens as appropriate
            if cur_node.entries:

                # - Do not annotate leading/trailing separators, but annotate all covered word tokens,
                #   and only 'inner' separators (i.e., between first/last word tokens).
                first_word = word_positions[0]

                # All tokens from first_word to last_word inclusive are covered,
                # annotate all word tokens there, and annotate non-word tokens
                # only if they're not at the edges (i.e., not before first/after last word)
                # for each node.entries, annotate appropriately
                for token_idx in range(first_word, last_word+1):
                    if is_word[token_idx]:
                        annotations[token_idx].update(cur_node.entries)
                    else:
                        # Only annotate non-edge separators
                        if token_idx != first_word and token_idx != last_word:

            while i < N and not is_word[i]:

            if i >= N:

            next_word = normalized[i]
            next_node = cur_node.children.get(next_word)
            if next_node is None:

            word_positions.append(i)
            cur_node = next_node
            i += 1

    return [(tok, annotations[i]) for i, tok in enumerate(tokens)]
