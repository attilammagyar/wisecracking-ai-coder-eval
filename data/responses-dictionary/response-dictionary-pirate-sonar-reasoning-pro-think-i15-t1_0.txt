## **Solution Overview**

To solve the text annotation problem efficiently using built-in Python libraries, we focus on two key components:

1. **Dictionary Preprocessing**  
   Convert the raw dictionary into optimized data structures:
   - **Case-insensitive exact matches**: Map lowercased words to their IDs.
   - **Component sequences**: Preprocess phrases into token sequences (splitting on non-alphanumeric characters) and map these sequences to dictionary entry IDs, handling case insensitively.

2. **Annotation Algorithm**  
   For each token in the input:
   - **Individual matches**: Check if the token (lowercased) exists in the dictionary.
   - **Compound phrases**: Iterate through all possible token spans (starting from the current token), ignoring separators, to identify multi-word compounds that match preprocessed component sequences.

## **Implementation**

```python
import re
from collections import defaultdict

def build_dictionary_index(dictionary):
    """Preprocess the dictionary into optimized lookup structures."""
    exact_map = defaultdict(set)
    component_map = defaultdict(set)

    for key, value in dictionary.items():
        # Case-insensitive exact matches
        exact_key = key.lower()
        exact_map[exact_key].add(value)

        # Preprocess component sequences (ignore separators)
        components = re.split(r'[\W_]+', key.strip())
        components = [c.lower() for c in components if c]
        if components:
            component_tuple = tuple(components)
            component_map[component_tuple].add(value)

    return {
        'exact_map': exact_map,
        'component_map': component_map,
        'max_component_length': max(len(comp) for comp in component_map) if component_map else 0
    }

def annotate(tokens, dictionary_index):
    """Annotate tokens using preprocessed dictionary structures."""
    annotated = [(token, set()) for token in tokens]
    exact_map = dictionary_index['exact_map']
    component_map = dictionary_index['component_map']
    max_length = dictionary_index['max_component_length']

    def is_sep(t):
        return not t.isalnum()

    for i in range(len(tokens)):
        token = tokens[i]
        # Handle individual matches
        if not is_sep(token):
            lower_token = token.lower()
            if lower_token in exact_map:
                annotated[i][1].update(exact_map[lower_token])

        # Check for compound phrases
        for l in range(1, max_length + 1):
            comp = []
            j = i
            while len(comp) < l and j < len(tokens):
                t = tokens[j]
                if not is_sep(t):
                    comp.append(t.lower())
                j += 1
            if len(comp) != l:
                break  # Not enough tokens to form sequence

            # Check if this component sequence exists
            comp_tuple = tuple(comp)
            if comp_tuple in component_map:
                ids = component_map[comp_tuple]
                # Annotate all tokens from i to j-1 (includes separators in between)
                for k in range(i, j):
                    if k < len(annotated):
                        annotated[k][1].update(ids)

    return [tuple(a) for a in annotated]
```

## **Key Design Features**

| Component | Description | Example |
|----------|-------------|---------|
| **Exact Matches** | Lowercased words map directly to IDs. | `"a" → 1`, `"AAA" → 1` |
| **Component Sequences** | Phrases split by non-alphanumeric separators. | `"Aaa BBB" → ["aaa", "bbb"] → ID 3` |
| **Efficient Lookup** | Preprocessed structures allow O(1) checks for matches and O(n²) spanning (optimized for clarity over raw performance) | `["black", "swan"]` matches `3` for `"black swan"` in 1 list traversal pass |

This solution prioritizes readability and correctness while handling all edge cases in the provided test suite. The algorithm efficiently annotates separators within compounds while ignoring them during component matching, ensuring accurate handling of multi-word phrases.
