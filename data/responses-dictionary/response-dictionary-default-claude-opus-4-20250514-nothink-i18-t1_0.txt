## Algorithm Design

### Data Structure for Dictionary Index

I'll use a **trie (prefix tree)** to efficiently store and lookup dictionary entries. The trie will:
- Store normalized (lowercase) words/phrases
- Handle both individual words and multi-word phrases
- Support efficient prefix matching for finding all possible phrases starting at a given position

Each trie node will store:
- Children nodes (for continuing the word/phrase)
- Set of dictionary entry IDs that end at this node
- A flag indicating if this node represents a word boundary (for phrases)

### Lookup Algorithm

1. **Normalize tokens**: Convert to lowercase for case-insensitive matching
2. **Classify tokens**: Identify word vs non-word (separator) tokens
3. **Find all matches**: For each position in the token sequence:
   - Try to match individual words
   - Try to match compound words (concatenated tokens)
   - Try to match phrases (words separated by non-words)
4. **Annotate tokens**: Collect all dictionary entries that include each token

### Key Insights

- **Word boundaries**: Non-word tokens create boundaries between words in phrases
- **Greedy matching**: We need to find ALL possible matches (not just longest/shortest)
- **Separator handling**: Inner separators in phrases get annotated, but not leading/trailing ones
- **Compound words**: Multiple consecutive word tokens without separators form a single lookup unit

import collections.abc
import re

class TrieNode:
    def __init__(self):
        self.children = {}
        self.entries = set()  # Dictionary entry IDs that end at this node
        self.is_word_end = False  # Marks end of a word in a phrase

class Trie:
    def __init__(self):
        self.root = TrieNode()
    
    def insert(self, phrase, entry_id):
        """Insert a phrase into the trie with its dictionary entry ID."""
        # Normalize and tokenize the phrase
        normalized = phrase.lower()
        words = re.findall(r'\w+', normalized)
        
        if not words:
            return
        
        # Insert as a single path in the trie
        node = self.root
        for i, word in enumerate(words):
            if word not in node.children:
                node.children[word] = TrieNode()
            node = node.children[word]
            if i < len(words) - 1:
                node.is_word_end = True
        
        node.entries.add(entry_id)
        node.is_word_end = True

def build_dictionary_index(dictionary: collections.abc.Mapping) -> object:
    """
    Build a normalized index from a dictionary for fast lookup of words and
    compound phrases.

    Parameters:
        dictionary: Mapping strings (keys) to meanings (values).
    """
    trie = Trie()
    for phrase, entry_id in dictionary.items():
        trie.insert(phrase, entry_id)
    return trie

def is_word_token(token):
    """Check if a token contains word characters."""
    return bool(re.search(r'\w', token))

def annotate(tokens: collections.abc.Iterable[str], dictionary_index: object) -> collections.abc.Iterable[tuple[str, collections.abc.Set]]:
    """
    Annotate tokens with entries from the dictionary.

    Parameters:
        dictionary_index:   A dictionary index created by build_dictionary_index()
        tokens:             The tokens to be annotated.

    Return:
        annotated_tokens:   A list containing (token, annotations) pairs for each token in tokens.
    """
    tokens = list(tokens)
    n = len(tokens)
    trie = dictionary_index
    
    # Initialize annotations for each token
    annotations = [set() for _ in range(n)]
    
    # Try to match starting from each position
    for start_pos in range(n):
        # Skip if starting with a non-word token (for phrases)
        if not is_word_token(tokens[start_pos]):
            continue
        
        # Try to match from this position
        node = trie.root
        word_buffer = []
        current_word = ""
        positions = []  # Track positions of all tokens in current match
        
        for pos in range(start_pos, n):
            token = tokens[pos]
            
            if is_word_token(token):
                # Add to current word
                current_word += token.lower()
                
                # If we have a complete word from previous tokens, process it
                if word_buffer and current_word == token.lower():
                    word = word_buffer[-1] if word_buffer else ""
                    if word and word in node.children:
                        node = node.children[word]
                        word_buffer = []
                    else:
                        # Can't continue this path
                        break
                
                # Check if we can continue in trie
                if not word_buffer:  # Starting a new word
                    word_buffer = [current_word]
            else:
                # Non-word token (separator)
                if current_word:
                    # Complete the current word
                    if current_word in node.children:
                        node = node.children[current_word]
                        if node.entries:
                            # Found matches - annotate all positions
                            for i in range(start_pos, pos + 1):
                                if i == pos and not is_word_token(tokens[i]):
                                    # Only annotate separator if it's not trailing
                                    if pos + 1 < n and is_word_token(tokens[pos + 1]):
                                        # Check if we can continue the phrase
                                        continue_possible = any(child_key in node.children 
                                                              for child_key in node.children)
                                        if continue_possible:
                                            for entry_id in node.entries:
                                                annotations[i].add(entry_id)
                                else:
                                    for entry_id in node.entries:
                                        annotations[i].add(entry_id)
                        
                        # Reset for next word in phrase
                        current_word = ""
                        word_buffer = []
                    else:
                        # Can't continue this path
                        break
            
            positions.append(pos)
            
            # Check for matches at current position
            if current_word and current_word in node.children:
                check_node = node.children[current_word]
                if check_node.entries:
                    # Annotate all tokens in this match
                    for i in range(start_pos, pos + 1):
                        for entry_id in check_node.entries:
                            annotations[i].add(entry_id)
    
        # Final check for any remaining word
        if current_word and current_word in node.children:
            check_node = node.children[current_word]
            if check_node.entries:
                for i in positions:
                    for entry_id in check_node.entries:
                        annotations[i].add(entry_id)
    
    # Create result
    annotated_tokens = []
    for i, token in enumerate(tokens):
        annotated_tokens.append((token, annotations[i]))
