## **Algorithm Overview**

1. **Dictionary Normalization**  
   Convert all dictionary entries to lowercase words, ignoring non-alphabetic characters. This avoids case mismatches and separator variations.

2. **Trie-Like Indexing**  
   Group entries by phrase length for quick lookups. For example, all 3-word phrases are checked before shorter ones.

3. **Greedy Matching**  
   Scan tokens left-to-right, always checking the longest possible phrase first. Once a phrase is found, annotate all tokens in that span (including inner separators).

4. **Dual Annotation**  
   After processing compounds, re-scan all tokens to add individual word annotations. This ensures tokens part of both compounds and standalone words get both IDs.

## **Implementation**

```python
import re
import collections

def is_word(token: str):
    return re.fullmatch(r'[a-zA-Z]+', token) is not None

def normalize_token(token: str):
    return token.lower()

def build_dictionary_index(dictionary: collections.abc.Mapping):
    phrase_map = collections.defaultdict(collections.defaultdict, dict)
    max_length = 0
    entry_data = {}  # For dev purposes

    for original_key, original_id in dictionary.items():
        words = []
        for chunk in original_key.split():
            if is_word(chunk):
                words.append(normalize_token(chunk))
        normalized = tuple(words)
        if not normalized:
            continue  # Empty entries
        entry_len = len(normalized)
        phrase_map[entry_len][normalized].add(original_id)
        if entry_len > max_length:
            max_length = entry_len

    return (phrase_map, max_length)

def annotate(tokens, dictionary_index):
    phrase_map, max_length = dictionary_index
    annotated = [(token, set()) for token in tokens]

    # Process compound phrases first
    i = 0
    while i < len(tokens):
        max_possible = min(max_length, len(tokens) - i)
        compound_found = False
        
        for length in range(max_possible, 0, -1):
            words = []
            j = i
            while len(words) < length and j < len(tokens):
                if is_word(tokens[j]):
                    words.append(normalize_token(tokens[j]))
                j += 1
            
            if len(words) == length:
                if tuple(words) in phrase_map.get(length, {}):
                    ids = phrase_map[length][tuple(words)]
                    for pos in range(i, j):
                        if pos < len(annotated):
                            current_ids = set(annotated[pos][1])
                            current_ids.update(ids)
                            annotated[pos] = (tokens[pos], current_ids)
                    i = j
                    compound_found = True
                    break
        
        if not compound_found:
            i += 1

    # Add individual word annotations
    for idx, (token, ids) in enumerate(annotated):
        if is_word(token):
            lower_token = normalize_token(token)
            if 1 in phrase_map and (lower_token,) in phrase_map[1]:
                ids.update(phrase_map[1][(lower_token,)])
                annotated[idx] = (token, ids)
    
    return annotated
```

## **Key Explanations**

1. **Normalization**  
   Converts all dictionary entries to lowercase letter sequences, ignoring punctuation/whitespace. For example, "Black Swan" becomes `('black', 'swan')`.

2. **Efficient Lookup**  
   Organizes entries by word count (`phrase_map`). This allows O(1) access for any n-word sequence.

3. **Greedy Strategy**  
   Checks for the longest possible match starting at each position first. This ensures correct overlaps (e.g., "BBB CCC DDD" vs "BBB CCC").

4. **Dual Annotation**  
   - **Compound Pass**: Processes phrases, annotating all tokens in their span.  
   - **Word Pass**: Adds standalone word annotations, ensuring combined results.
