### **Algorithm Overview**
1. **Normalization**  
   - Dictionary entries are preprocessed to lowercase and concatenated alnum characters (e.g., "AAA, BBB" → "aaabbb").
   - For annotation, tokens are joined, converted to lowercase, and non-alnum characters removed to match dictionary entries.

2. **Annotation Logic**  
   - **Individual Tokens**: Check each token against normalized dictionary entries.
   - **Compound Phrases**: Iterate over all possible token sub-sequences, normalize them, and compare against the dictionary. Each token in a matching phrase is annotated with the corresponding entry.

### **Implementation**
```python
import re
from collections.abc import Iterable, Mapping

def build_dictionary_index(dictionary: Mapping) -> dict:
    """Build a normalized dictionary index for fast lookups."""
    normalized_phrases = {}
    for phrase, id in dictionary.items():
        normalized = ''.join(re.findall(r'\w+', phrase.lower()))
        normalized_phrases[normalized] = id
    return {'phrases': normalized_phrases}

def annotate(tokens: Iterable[str], dictionary_index: dict) -> Iterable[tuple[str, set]]:
    """Annotate tokens with dictionary entries. Two main steps: handle individual tokens and all possible phrases."""
    annotations = [set() for _ in range(len(tokens))]

    # 1. Annotate individual tokens
    for i, token in enumerate(tokens):
        normalized_token = re.sub(r'\W+', '', token.lower())
        if normalized_token and normalized_token in dictionary_index['phrases']:
            annotations[i].add(dictionary_index['phrases'][normalized_token])

    # 2. Annotate compound phrases (check all possible token sequences)
    for start in range(len(tokens)):
        for l in range(1, len(tokens) - start + 1):  # Check all possible phrase lengths
            end = start + l - 1
            phrase = ''.join(tokens[start:end+1])
            normalized_phrase = re.sub(r'\W+', '', phrase.lower())
            
            if normalized_phrase and normalized_phrase in dictionary_index['phrases']:
                phrase_id = dictionary_index['phrases'][normalized_phrase]
                for pos in range(start, end + 1):
                    annotations[pos].add(phrase_id)

    return [(token, ann) for token, ann in zip(tokens, annotations)]
```
